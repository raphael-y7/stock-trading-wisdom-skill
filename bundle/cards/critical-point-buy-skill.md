# 临界点买点决策

## R — 原文 (Reading)

> "在股票的操作上，这些点往往是公众对股价重新评估的点，也就是在这些点上，你入场的获胜概率最高。买股票的技巧，全在怎样找临界点上。"
>
> — 陈江挺《炒股的智慧》第四章第一节"何时买股票·基本原则"

> "选买点的最重要点是选择止损点。即在你进场之前，你必须很清楚，若股票的运动和你的预期不合，你必须在何点止损离场。……无论用什么方法，你必须有个止损点，这个止损点不应超出投资额的20％。"
>
> — 陈江挺《炒股的智慧》第四章第一节"何时买股票·基本原则"

---

## I — 方法论骨架 (Interpretation)

这张卡回答"这个突破/回调能不能买、买了止损设哪"。作者把买点定义为"临界点"——公众对股价重新评估的关键位置（类比水到100℃化汽），在这些位置入场获胜概率最高。

核心纪律有两条：

1. **买点与止损点是同一定义的两半**：进场之前必须先确定"走势不合预期时在哪个价位认输离场"；先想最多亏多少，再想赚多少。没有止损价的买入不是完整交易。止损幅度以10%以内为理想，任何情况不超过20%的硬上限，越小越好。
2. **买点必须自带失败判据**：五类经典临界点——升势突破前波峰（A点）、放量突破阻力线、回踩支撑线不破、倒头肩向上突破颈线、跌穿支撑线后快速弹回的假跌破——每个都天然对应一个"跌破即离场"的价位：升势中跌穿前波谷=升势被否定，跌回阻力线下=假突破，跌穿支撑线=下跌概率大过上升。

操作前提：先看大市（不好则什么都不买）、绝不在跌势中入市；突破必须放量确认，无量突破意义不大；建仓用 A点试探、B点确认后补足的两段法，符合"对胜利的把握越大，下的注就越大"。八条买入要点（见 E 段）专门拦截"跌了很多就买""有好消息就买"两类高频错误。

## A1 — 应用示例 (Application Example)

### 示例 1: A=15/B=13 升势买点与双止损设定

- **类型与来源**: 原书例题 + 图4-1，《第四章第一节"操作技巧·升势时的操作"》
- **问题/输入**: 正常升势，前波峰 A=15 元、前波谷 B=13 元。
- **方法论的使用**: 股价超过A点即为好买入点（买15.10元或15.50元）；止损点二选一——A−1元=14元，或B=13元，按个人风险承受力选择；无论如何，跌穿B点必须走人（高过A又击穿B=升势被暂时否定，须场外观望）；股价升到16.50元时，卖出/止损价上移到15.50元保本。
- **结论**: 入场触发价、止损价、失败判据、保本上移一次性确定。
- **结果**: 原书例题，未交代实际交易结果。

### 示例 2: 图4-7 假跌破支撑线后的买点

- **类型与来源**: 原书例证 + 作者经验自述 + 图4-7，《第四章第一节"关键:把握临界点"》
- **问题/输入**: 股价跌穿支撑线，交易量大增，且股价很快弹回支撑线之上（三要素同时满足）。
- **方法论的使用**: 机制=大户借跌破公认支撑引发恐慌性抛售、低位吸纳，放量+快速收复暴露其意图；在反弹确认处（A点）买入，止损仍设支撑线之下；其后再突破前高（B点）可加仓。
- **结论**: 极佳买入机会。
- **结果**: 作者自述"碰到这样的机会十次中有九次赚钱"——个人经验概率，无样本量与第三方佐证（引用时保留该限定）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 看到某股放量突破前高/阻力线/颈线，问"现在能不能追、追了止损设哪"；
2. 看到某股跌穿支撑线又快速收回，问"是不是假跌破、能不能抄底"；
3. 选股已完成，问"什么时候入场、怎么定止损"；
4. 用户说"这股票从高位跌了很多了，是不是可以买了"或"有好消息/专家推荐，能进吗"——需要拦截时。

### 语言信号 (用户的话里出现这些就应激活)

- "能不能买""可以追吗""买点""入场点""临界点""突破买入""止损设在哪"
- "假突破""假跌破""回踩支撑""破位反弹""颈线突破""A点B点"
- "跌这么低了能不能抄底""有利好能买吗"
- 英文: "breakout buy" / "entry point" / "where to set stop loss" / "false breakdown buy"

### 与相邻 skill 的区分（初稿，阶段 3 回填定稿）

- 与 `sell-trailing-stop-skill` 的区别: 本卡管买点（何时买、止损设哪）；对方管卖点（有利润后怎么卖、移动止损怎么沿浪谷上移）。
- 与 `money-management-skill` 的区别: 本卡定"位置"（触发价+止损价+失败判据）；对方定"仓位大小"（下注多大、分仓加码、1:3风险报酬比）——本卡只输出仓位建议提示，不计算注码。
- 与 `ma250-system` 的区别: 本卡是图形态临界点的细读（前峰前谷、支撑阻力、颈线、量价）；对方是2016再版给新手的250日线最小规则系统，不做图形细读——用户要"简单均线规则"时用对方。
- 与 `stock-picking-skill` 的区别: 本卡回答"何时买"；对方回答"买什么"（大市→牛劲类别→龙头三步过滤）。

## E — 可执行步骤 (Execution)

**必需输入**: 前一波峰价位（A）与前一波谷价位（B，升势形态时）；阻力线/支撑线价位（及颈线，形态形态时）；突破当日成交量与均量对比（倍数）；现价；可选：拟入场当日最低价（用于"当天最低点法"定止损）、大市状态。以上缺失时先询问，不得静默猜值（尤其前峰前谷、支撑阻力位、量能倍数）。

**交付物与完成标准**: 结论=买/不买（附理由）+触发价+止损价+失败判据（跌破何价即离场）+仓位建议提示（注码计算转 `money-management-skill`）。触发价、止损价、失败判据三价齐全才算完成；"不买"时必须指明违反的具体条款。

当 skill 被激活后，按以下步骤执行：

1. **前置否决检查**
   - 判停条件: 大市不好 → 输出"什么都别买，安坐不动"（看到很吸引人的临界点也不轻易动作），流程终止；个股处于明确跌势 → 买入要点⑤"绝不要在跌势时入市"，流程终止。
   - 完成标准: 大市状态与个股趋势方向均有明确记录。

2. **买点类型识别（五选一，输出触发价与失败判据）**
   - 完成标准: 以下之一成立且三价齐备——
     - ① 升势突破前波峰A（图4-1）: 触发=越过A（如A=15元则买15.10–15.50元）；失败判据=跌穿前波谷B（如13元）→升势被否定→离场观望，流程终止。
     - ② 放量突破阻力线（图4-2）: 触发=放量站上阻力线（止损设阻力线下0.5–1元，如15元阻力线止损14.50或14元）；判停条件=无量突破→不作有效突破，流程终止；失败判据=跌回阻力线之下→假突破（可能是大户搞鬼）→止损离场。
     - ③ 回踩支撑线不破（图4-3）: 触发=触及支撑线反弹；止损=支撑线之下；失败判据=跌穿支撑线（此后下跌概率大过上升）→离场。
     - ④ 倒头肩/倒双肩向上突破颈线（图4-5）: 操作法同②，止损设颈线略下；正双肩只标卖点、不提供买点。
     - ⑤ 假跌破支撑线弹回（图4-7）: 三要素同时满足（跌穿支撑线+交易量大增+很快弹回支撑线之上）→触发=反弹确认处（A点）；止损=支撑线之下；失败判据=再度跌回支撑线下方。

3. **八条买入要点逐条核对**
   - 完成标准: ①买入前参照走势图（大众投资心理的反映）②先定止损点、搞清楚最多愿亏多少并切记照办③选获胜概率大过失败概率的临界点（不可能每次正确）④最好在升势或突破阻力线、准备开始升势时买⑤绝不在跌势入市⑥不以"已跌很低"为理由（不知道它还会跌多少）⑦不以"好消息/专家推荐"为理由（尤其消息公布前已升一大截）⑧点点照办——任一违反即放弃本次买入并注明违反的条款。

4. **止损合规检查**
   - 完成标准: 止损价确定且亏损幅度≤10%为理想、任何情况不超过20%硬上限；低价股按绝对值放宽（原书口径: 5元股给0.75元空间→止损4.25元；50元股给3元→47元）；作者偏好法=定在入市当天最低点（"入场点选得正确，股票开始上升，它不应跌回到我当天入场的最低点"）。

5. **建仓与加码路径**
   - 完成标准: A点（临界点首次触发）先进计划量的20–30%，其余在B点（回调后再突破上回波浪高点）确认后买入；B点不出现则维持A仓位；两段之间跌破止损同样离场。注码大小转 `money-management-skill`。
   - 判停条件: 止损被触发后股价立即回头（假摔）→ 可按规则重入，再入场点参照上一波的高点；亏的钱=买了保险。若选择不重入，也不得因假摔而放大下一次的止损。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只有基本面消息、没有图形与量价数据时——临界点判定无从谈起，先取数或转基本面审视。
- 用户问"买什么股票/哪个板块牛劲足" → `stock-picking-skill`；问"下注多大/怎么分仓" → `money-management-skill`；问"什么时候卖/利润怎么保住" → `sell-trailing-stop-skill`。
- 用户明确要最简单的机械规则、不愿读图 → `ma250-system`。
- 无势横盘股——原书口径"一只无势的股票通常不适合炒作"，临界点策略不适用于无趋势标的。

### 作者在书中警告的失败模式

- 听内幕消息与专家推荐买入，尤其消息公布前股票已升一大截——那可能是"找最后的傻瓜"。
- 把"股价已跌了很低了"当买入理由——"别试着去接往下掉的刀子，它会把你的手扎得血淋淋的"（40→20美元例: 你不知道它还会跌多少；从40跌到10再回升到20才是两码事——趋势已转才可考虑）。
- 找机械绝招: "如果炒股居然简单到'20天平均线穿越50天平均线是买入好点'的话，哪里还有人起早摸黑去上班？"——找不到支撑其心理脉络的临界点常常靠不住。
- 没有止损点的买入、被套后向下摊平（摊平是"破产的捷径"，铁律禁止）。

### 作者的盲点 / 时代局限（阶段 0 批判）

- "十次中有九次赚钱"等胜率为作者个人自述，无样本量、无基准对照（幸存者偏差）。
- 临界点机制依赖"公众心理共识+大户做盘"叙事，出自1980–2005美股与1990s A股庄股语境；现代A股量化交易、涨跌停与T+1下，假跌破/假突破的发生率与形态存疑，突破当日买入可能因涨停无法成交。
- 目标价无算法: 原书未给卖出目标价，风险报酬校验的目标端只能以图形参照（前高/阻力位）由使用者自选——这是原书明示的缺口，不得补造公式。
- 突破买点对滑点与手续费敏感，高频假突破序列的交易成本原书未讨论。

### 容易混淆的邻近方法论

- `sell-trailing-stop-skill` / `money-management-skill` / `stock-picking-skill` / `ma250-system`: 见 A2 区分。
- 大户操纵痕迹识别: 假跌破=恐慌吸纳、假突破=诱多的机制解释在对方；本卡直接按三要素/失败判据执行，不揣测动机。
