# 基本面快速审视

## R — 原文 (Reading)

> "基本面分析主要分析公司的小环境，大环境的情况太过复杂……大环境的变化是谈天的好材料，用来炒股的实用性不大。……如果只靠走势图来炒股票，不知道公司到底是干什么的和干得怎么样，心里虚得很。"
>
> — 陈江挺《炒股的智慧》第二章第一节"基本面分析的基本知识"

---

## I — 方法论骨架 (Interpretation)

这张卡解决"只看图炒股心里虚"的问题: 在按图形找买卖点之前，用一份固定清单快速核对"这家公司是干什么的、干得怎么样"。它不是估值方法，也不预测股价，只是技术分析的**底层校验**——作者引彼得·林奇的话说，"我每年花在经济大势上的分析时间不超出15分钟"。

核对范围三块:

1. **大环境八项只作背景**。利率、税收、汇率、银根松紧、经济周期、通胀、政治环境、产业政策——各记一个方向性影响即可（利率升→负面、银根松→正面、产业扶持→正面……），日常选股不据此行动；对大环境的日常判断交给"大市"。
2. **小环境五项是重点**。①营业收入有无快速发展势头；②盈利（经营好坏以盈利衡量）；③固定资产相对市场总价是否低估；④同类公司对比；⑤品牌价值。
3. **最可能导致股价上涨的三因素**。①盈利增长（最重要——增速要有合理基数、必须建立在销售收入真实增长上、与收入增速背离要调查、加速增长是股价成倍上翻的前兆）；②新产品（不限于实物，含新概念/新推销手法/新管理方式）；③公司回购自身股票（信任票+流通量减少增厚每股盈利）。

两个附加提醒: 成本收益比（PE）"概念上对，炒股上实用性不大"，不作一票否决；研读财报须留意收入确认口径与固定资产折旧的水分。原书为**定性清单，无任何财务指标阈值**——结论只到"红旗项+定性判断"，不到评分。

## A1 — 应用示例 (Application Example)

### 示例 1: 微软的高市盈率——别拿PE当否决票

- **类型与来源**: 原书转述，第二章第一节"导致股价上涨的三个因素·盈利的增长"。
- **问题/输入**: 新手常把成本收益比率（股价÷收益）当作"股价是否便宜"的衡量标准。
- **方法论的使用**: 微软上市初期PE超过100（作者写作时也超50）——单看PE会否决它；但盈利增长才是最重要的涨价因素，"13年前你买了1万美元微软的股票，今天就是百万富翁"。PE这个概念"从根本上来说是对的，但在炒股上实用性不大"。
- **结论**: 快速审视以盈利增长质量为核心，PE只作背景参考，不作一票否决。
- **结果**: 原书转述的市场历史结果。

### 示例 2: 王安电脑——"新产品"因素的力度与保质期

- **类型与来源**: 原书转述，第二章第一节"新产品"；作者另在第五章以同一家公司作"不要向下摊平"的反面教材。
- **问题/输入**: 王安电脑凭新型文字处理机，1978–1980年间股价升13倍。
- **方法论的使用**: 新产品提供盈利快速增长的可能，是涨三因素中弹性最大的一项；同段对照——新态公司1963年口服避孕药6个月翻5倍、麦当劳概念成形初期1967–1971年4年翻11倍。
- **结论**: 命中"新产品"→核对表加分；但须持续验证——同一家王安电脑其后衰落破产（作者在"不要向下摊平"一节引为教训，"曾是美国第二大电脑公司"），单一因素的爆发力不保证公司长存。
- **结果**: 原书转述的历史结果（13倍与其后破产均为原书转述）。

### 示例 3: 小环境五项+三因素合成核对

- **类型与来源**: 原书未提供完整走查案例；以下为**合成演练**（虚构公司，口径对齐阶段1.5的V2纸面演练）。
- **问题/输入**: 虚构制造业公司"丙电子"（合成）: 营收8亿→14亿（+75%）；盈利0.6亿→0.7亿（+17%）；固定资产9亿、总市值40亿；新能源车连接器新品放量；上月公告回购2%股本。大环境八项已记背景（利率下行、产业政策扶持），不驱动结论。
- **方法论的使用**: 小环境五项逐项过——①营收有快速发展势头✓；②盈利增但增速17%远低于营收75% → 触发"背离须调查"规则（是否同类竞争者增多、削价求售？）→ 若属实"这只股票的升幅也就有限了"；③固定资产9亿 vs 市值40亿 → 无明显低估（原书参照例: 市场总价10亿而固定资产15亿才算股价偏低）；④同类公司对比、⑤品牌价值 → 资料不足，标注待补。涨三因素——盈利未出现加速增长（不满足"25%提速到40%–50%"形态）；新产品✓；回购✓ → 2/3。
- **结论**: 定性=中性偏正，但须先查清"增收不增利"的原因；作为后续技术分析/买点决策的底层校验，不构成买入信号。
- **结果**: 合成演练输出；原书为定性清单、无财务阈值，不做评分。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 问"这家公司是干什么的、基本面怎么样""这票能不能碰"——买入前想核一遍公司经营事实；
2. 看到一只涨得好的股票，问"它涨有基本面支撑吗，还是纯炒作"；
3. 财报季问"营收大增但利润没增，怎么看""这增速是真的吗"；
4. 问"PE这么高能不能买""公司回购是利好吗"。

### 语言信号 (用户的话里出现这些就应激活)

- "基本面""主营业务""公司干什么的""经营情况"
- "营收""营业收入""盈利""净利润""增速""增收不增利"
- "固定资产""品牌""同行对比""回购""新产品"
- "市盈率""PE""成本收益比""财报""会计游戏"
- 英文: fundamentals / revenue growth / earnings growth / PE ratio / company check

### 与相邻 skill 的区分（初稿，阶段 3 回填定稿）

- 与 `stock-picking-skill` 的区别: 本卡是**单一公司的定性检查**（这家公司本身干什么的、干得怎么样）；对方是**类别与强度筛选**（现在该买什么类别、选哪只龙头）。顺序上可先筛后核、也可先核后筛，两层问题互不替代。
- 与技术分析类工具（`motion-normality-skill` 及K线形态类）的区别: 本卡只看**公司经营事实**（营收/盈利/资产/品牌/回购/产品），不看图、不用量价；技术卡不看财报。作者口径: 基本面、技术分析、大市三者共振时胜算最大——本卡只负责其中"基本面"一角。
- 与 `critical-point-buy-skill` 的区别: 本卡不输出买卖触发，只输出"通过/不通过底层校验+红旗项"；触发与止损由买点卡承接。

## E — 可执行步骤 (Execution)

**必需输入**: ①公司主营业务（干什么）；②营收与盈利的近期趋势（至少两期数据与同比增速）。可选: ③固定资产与总市值；④同类可比公司；⑤新产品/回购公告。①②缺失时**先询问，不得静默猜值**；③④⑤缺失时输出"资料不足"并标注哪些项未核对，**不得用常识补成作者方法**。

**交付物与完成标准**: ①逐项清单核对结果（大环境八项标"背景"；小环境五项各给✓/✗/资料不足；三因素各给满足/不满足/资料不足）；②红旗项列表；③一句话定性结论（偏正/中性/偏负+依据）；④固定声明——本卡为定性清单，原书无财务指标阈值，不构成买卖信号。四件齐备才算完成。

当 skill 被激活后，按以下步骤执行:

1. **划定范围: 大环境八项只作背景**
   - 完成标准: 利率/税收/汇率/银根松紧/经济周期/通胀/政治环境/产业政策八项各记一个方向性影响或标"不适用"；明确声明"大环境不进入结论权重，大市的日常判断另行处理"。

2. **小环境五项逐项核对**
   - 完成标准: ①营业收入有无快速发展势头（原书例: 去年1亿、今年2亿、明年预计4亿）；②盈利情况（经营好坏以盈利衡量）；③固定资产相对市场总价是否明显低估（原书参照例: 市场总价10亿而固定资产15亿 → 股价偏低）；④同类公司情况对照；⑤品牌价值。五项各给✓/✗/资料不足三值之一。

3. **涨三因素核对**
   - 完成标准:
     - 盈利增长（最重要）: 基数检查（每股1分→2分的100%无意义，5角→1元的100%才有效；年增25%≈3年翻倍）；收入前提（销售收入无法增长时，盈利增长通常是玩会计游戏 → 红旗）；增速背离调查（如收入+100%而盈利仅+20% → 必须调查是否竞争加剧削价求售；属实则"升幅有限"）；加速信号（增速从25%突然提速到40%–50%，通常铺好股价成倍上翻的道路）。
     - 新产品: 有无新产品/新概念/新推销手法/新管理方式。
     - 公司回购: 有无回购（对本公司投信任票+流通量减少增厚每股盈利）；附带留意流通盘总数越大越难推升。

4. **红旗汇总与判停**
   - 完成标准: 汇总红旗项（疑似会计游戏、收入确认口径可疑、增速背离未查清、低基数假增速）。
   - 判停条件: 命中"收入不增长的盈利增长"或背离调查未通过 → 结论=暂不通过底层校验，建议先调查清楚再谈买点，流程终止。

5. **财报水分提示**
   - 完成标准: 提示两类已知水分点——销售收入确认口径（收到钱/发了货/连订单都算在内，各有不同算法，发货能否收到钱、订单会不会取消都是问题）与固定资产折旧（"旧机器送人都没人要，纸面上还值不少钱"）；注明作者仅提示留意、未给核查方法。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要估值定价（算内在价值/合理价位/目标价）→ 本卡不做估值；原书"现金值法"作者自认结论是"猜"、明示不构成买卖信号，只可作背景理解。
- 需要深度财务分析（三表勾稽、现金流质量、杜邦拆解等）→ 原书无此内容，本卡只有快速定性清单，不得伪装成深度尽调。
- 没有任何经营资料、只想按图形交易 → 如实声明"底层校验缺失"（作者原话: 这样"心里虚得很"），由用户决定是否补资料。

### 作者在书中警告的失败模式

- **财务游戏**: "盈利增长的前提是销售收入的增长。一个公司的销售收入如果无法增长，盈利增长通常是玩会计游戏的结果。"
- **收入确认与折旧的水分**: 有的公司收到钱才算收入、有的发了货就算、更有的把订单都算在内；固定资产按买价减折旧"得到的数字可能很漂亮，其实没多大意义"。
- **单看PE错过高增长**（微软例）；反过来也不因"PE低"就当便宜——PE不是好的买卖标尺。
- **假账风险**（作者答读者问）: 假账被抓住之前无法核实真伪，但知情人会先抛售，痕迹显现在价格与交易量上——按危险信号规则执行可大致避开（该防护由技术面承接，本卡无法从财报识别假账）。

### 作者的盲点 / 时代局限（阶段 0 批判）

- **全定性、无财务指标阈值**: "干得怎么样"没有量化标尺（增速多快算"快速发展势头"只有举例没有判据），结论含主观成分——这是原书明示的缺口（t08 缺口记录），不得补造阈值冒充作者方法。
- 大环境八项为教科书式定性传导（如汇率→出口受损），未涉及现代央行沟通与全球流动性框架；部分传导在现代环境更复杂。
- 案例多为1980–90年代美股（微软/王安/麦当劳/新态公司），行业结构与信息披露环境已变；"避孕药6个月5倍"类单事件不可复制。
- 品牌估值（"可口可乐名字值500亿美元"）为"有人估算过"的转述，无出处可考。

### 容易混淆的邻近方法论

- 价值投资的公司分析（作者转述巴菲特选公司六条，列作交叉参照）: 本卡不是选伟大企业的长线框架，是短炒体系里的底层校验，语境不同不得混用。
- "大环境"与"大市": 宏观环境（利率汇率等）不等于指数走势（大市）——作者明确大环境"实用性不大"，日常方向判断由大市分析承接，本卡不越界替代。
