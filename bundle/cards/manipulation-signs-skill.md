# 大户操纵痕迹识别

## R — 原文 (Reading)

> "以我自己的经验，如果股价跌穿支撑线，交易量大增且股价很快弹回支撑线之上，这是极佳的买入机会。"我自己碰到这样的机会十次中有九次赚钱。"
>
> — 陈江挺《炒股的智慧》第四章第一节"关键:把握临界点"（图4-7 说明段）

---

## I — 方法论骨架 (Interpretation)

1. 证据原则是"钱不撒谎"：小股民无法核实消息真伪（名嘴可以在高位忽悠大家买股自己卖），唯一可信的是股价与交易量的真实变动——消息只有反映到量价上才算数。
2. 大户行为有一个生命周期（第三章第二节）：吸筹期缓慢吸纳、不想上头条（量温和放大、股价一步步抬升）→ 吸筹完毕后公开推荐、配合好消息（推升期）→ 好消息全部反映在股价中后开始派发，因筹码太大不能直砸市场，就令股价暴升引散户蜂拥接货 → 找足"傻瓜"全身而退，此后再无大买主推高股价。
3. 想买进时的两种手法：要么静悄悄吸（量增加但不明显、股价缓慢走高），要么砸破大家公认的好卖点、制造恐慌性抛售后在低位吸纳。想卖出时也有两种：要么先拉出狂升引发贪念让人抬轿，要么制造公众公认的好买点（假突破诱多）。
4. 核心痕迹是图4-7的假跌破：跌穿支撑线＋交易量大增＋很快弹回支撑线之上，三要素同时满足＝恐慌盘被吃掉的痕迹，暴露大户吸筹意图，此时是极佳买点。
5. 反向痕迹在顶部：突破阻力线后跌回线下＝假信号（"可能是大户搞鬼"）；缓升途中无消息暴升、放量冲高回落＝危险信号；升了一段后放巨量而价格不升＝有人出货。
6. 对手思维：你买的股票都是别人卖给你的——下单前想象对手是谁；对手是大户则你常亏，是散户则你常赢。
7. 边界铁律：操纵只能改变每天的或短期的波动，不能改变大势——长线投资者可以不必理会；本卡所有结论只对短线操作有含义。
8. 消息面两条鉴别：股评推荐要看图形位置（刚突破好临界点+有暗中囤积迹象→可怀疑联手推升、跟随尚有赢面；已暴升很多再推荐→找最后的傻瓜）；假账无法核查→默认真账＋盯量价＋严格执行危险信号即可大致避开。

## A1 — 应用示例 (Application Example)

### 示例 1: 图4-7 跌穿支撑线即刻反弹＝恐慌吸纳的机制讲解
- **类型与来源**: 原书例题/图示（第四章第一节"关键:把握临界点"图4-7及其说明段；案例验证 c45 逐字核对；"十次中有九次赚钱"为作者个人经验自述、无样本量）。
- **问题/输入**: 股价跌穿了大家公认的支撑线——这是真破位还是假跌破？
- **方法论的使用（机制推演）**: 作者让读者换位想象——你是有钱的大户，握有一批该股筹码，且已得到内幕消息（公司很快有好消息公布）：你会先抛售手中的股票、让股价跌破支撑线，因为跌破支撑线会引发市场恐慌性抛售，这时你在低位大量吸纳。因此三要素——跌穿支撑线、交易量大增、很快弹回支撑线之上——同时出现时，"跌破后迅速收复"暴露了意图：恐慌盘被大户吃掉了。对号生命周期＝处于吸筹/砸盘吸纳阶段而非派发；消息面暂无解释，反而佐证只按量价行事（钱不撒谎）。
- **结论**: 这是假跌破，A点（弹回确认处）是原书明示的"极佳买入机会"；操作上承接临界点买点卡——止损仍设在支撑线下方。
- **结果**: 作者自述"我自己碰到这样的机会十次中有九次赚钱"（个人经验概率，引用须保留该限定；无独立统计）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 个股跌破支撑线后一两天内放量拉回，怀疑"是不是主力砸盘吓散户、顺便吸筹"。
2. 股票放量突破阻力线后又跌回线下，怀疑突破是假的、有人在制造买点出货。
3. 持股缓升途中突然无消息暴升又冲高回落，或放巨量却不涨，问"是不是在出货、我要不要跑"。
4. 股评/名嘴强力推荐某股，问"该不该跟、是不是庄家在找人抬轿"。
5. 想确认某股低位温和放量缓涨"是不是有人在悄悄吸筹"。

### 语言信号 (用户的话里出现这些就应激活)

- "是不是庄家/主力在做盘""有没有人操纵""这票有庄吗"
- "假突破""假跌破""砸盘吸筹""吓出散户""诱多""找人抬轿"
- "放量不涨是不是出货""突破又回落什么意思""跌穿支撑又拉回来"
- "股评推荐能不能跟""名嘴喊单""manipulation / smart money / pump and dump / false breakout"

### 与相邻 skill 的区分

- 与 `motion-normality-skill`（运动正常性判定）的区别: 对方判定"走势还正常吗、该不该持有"（健康度结论）；本卡解释"**为什么不正常——是谁在做盘**"（机制归因），输出疑似操纵类型。对方的"异常"结论可由本卡给出机制解释，但两卡的问句不同。
- 与 `bubble-mania-skill`（泡沫识别）的区别: 对方识别**全市场/全板块**的疯（六特性、参与退出战略）；本卡只看**单只个股**的做盘痕迹，不判断市场级泡沫。
- 与 `critical-point-buy-skill`（临界点买点决策）的区别: 对方给出五类买点的触发与止损设定；本卡只负责"这个异动是不是做盘痕迹"的判定，假跌破确认后的买入执行转对方。

## E — 可执行步骤 (Execution)

**必需输入**: ①量价数据：近期K线与成交量（重点：支撑线/阻力线/前浪高的关键价位；异动当日及前后数日成交量相对平时均量的倍数）；②消息面时间线：异动前后有无公告、利好、股评推荐及其发布时点；③若问"该不该跟推荐"：推荐发布时股价的图形位置（是否刚突破临界点、此前有无囤积迹象）。缺量价数据或关键价位时先询问，不得凭"感觉像有庄"下结论；消息面缺失时按纯量价核对并注明。

**交付物与完成标准**: 疑似操纵类型（静默吸筹/砸盘恐慌吸纳/拉高引贪念/制造好买点出货之一，或"未见原书定义的操纵痕迹"）＋逐项痕迹证据表（每项命中/未命中＋量价证据）＋对操作的含义（买点参考/离场/回避/不理会）＋边界提示。所有痕迹必须出自原书清单，不得补造原书没有的痕迹类型；不揣测无法从量价观察的动机。

当 skill 被激活后, agent 应按以下步骤执行:

1. **痕迹清单逐项核对（每项输出命中/未命中＋量价证据）**
   - 假跌破支撑: 跌穿支撑线＋交易量大增＋很快弹回支撑线之上（三要素须同时满足）→ 恐慌性吸纳痕迹，A点（弹回确认处）为原书"极佳买入点"。
   - 假突破阻力: 突破阻力线后跌回线下 → 早先的穿越是假信号，"可能是大户搞鬼"；注意无量突破意义不大（突破必须有量确认）。
   - 无消息暴升: 缓升途中突然暴升＋交易量突增＋冲高回落（对齐50→55→62→58→64→61样板）→ 大户拉高吸引散户接货的危险信号。
   - 量增价滞: 升了一段后交易量猛增而价格不升 → "有人趁这个机会在出货"，短期到顶信号。
   - 静默吸筹: 交易量增加但不明显、股价一步步升高、不上报纸电视头条。
   - 股评鉴别: 刚突破好买入临界点＋此前有暗中囤积迹象 → 可怀疑股评人与大户联手推升，跟随尚有赢面；股票已暴升很多再推荐 → 找最后的傻瓜，回避。
   - 完成标准: 六项痕迹各有一句证据，命中项注明对应手法。

2. **生命周期定位**
   - 把当前量价与消息位置对号: 吸筹期（温和放量缓升、不上头条）→ 推升期（吸筹完毕开始公开推荐、好消息出现）→ 派发期（好消息全部反映后令股价暴升找傻瓜）→ 退场（再无大买主推高）。
   - 完成标准: 输出所处阶段＋对号证据。

3. **判停**
   - 痕迹清单全部未命中 → 输出"未见原书定义的操纵痕迹"，按运动正常性卡处理走势本身，不继续揣测动机。
   - 完成标准: 判定路径终止于唯一结论（某类型痕迹/无痕迹）。

4. **输出操作含义与边界**
   - 假跌破 → A点买点参考＋止损设支撑线下方（买入执行承接临界点买点卡）。
   - 假突破/无消息暴升/量增价滞 → 离场或回避（承接运动正常性与卖点卡）。
   - 长线投资者 → 按原书可不必理会（"操纵只能影响股票的短期波动，不能影响大势"）。
   - 假账疑虑 → 默认真账＋盯量价异常＋严格执行危险信号（原书三层防护）。
   - 完成标准: 输出含"类型＋含义＋边界提示"三字段，结论可检查。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 指数权重股、高流动性大市值标的上的日常波动——本卡痕迹基于"手握巨资的大户调动公众心理"的庄股叙事，在高流动性标的上发生率和形态适用性显著下降；硬套会把正常波动误读为操纵。
- 无量价数据、只有消息和传闻时——本卡唯一证据是量价，无证据不得下"有庄"结论。
- 预测大势方向——原书铁律：操纵不能改变大势，本卡结论只对短期波动有意义。
- 把一切异动都归因操纵——不正常≠必跌（也可能真有利好），且"将自己炒股失败归咎于股市受到操纵是失败者为自己的失败找借口"（第八章问答）。
- 判断全市场狂热/泡沫——那是泡沫识别卡的领地。

### 作者在书中警告的失败模式

- 追暴升无消息的股票：两周20→40元级暴升、最后两天量猛增而无特别好消息＝"我在吸引最后的傻瓜入场"，追入者恰是接棒人（第四章卖招4）。
- 把放量当健康信号：量增价滞时继续持有甚至加仓，不知不觉替大户接货（第四章卖招5）。
- 轻信股评与内幕：好消息公布前股价已升一大截时按消息买入＝充当兑现对手盘（第四章买入要点⑦）。
- 用操纵当替罪羊：把亏损归咎于"股市被操纵"而不做错误归因，永远学不到东西（第八章问答）。

### 作者的盲点 / 时代局限

- 整套"大户做盘"叙事基于1990年代美股庄股与更早的A股庄时代；现代A股的量化交易、涨跌停、T+1与信息披露监管已改变"刻意砸盘吸筹"的发生环境与微观形态，痕迹可能变形或失效（阶段0批判明确列出此假设未被证明）。
- "十次中有九次赚钱"为作者个人自述，无样本量与第三方佐证，不能当作该买点的期望胜率。
- 判定依赖"大户做盘"的动机假设，动机本身不可观察——使用上应以可观察的量价痕迹为准，不揣测动机；结论是"疑似"而非"实锤"。
- 作者的对手盘思维（"你买的都是别人卖的"）在无单一主导资金的市场中退化为一般流动性思考，不能再指向具体"大户"。

### 容易混淆的邻近方法论

- `motion-normality-skill`：健康度判定（正常/异常）vs 机制归因（谁在做盘）；共享危险信号样板但问句不同。
- `bubble-mania-skill`：个股做盘痕迹 vs 全市场疯的六特性。
- "钱不撒谎"（第二章第二节）：本卡的证据原则本身，融于方法不单独执行。
