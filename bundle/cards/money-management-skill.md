# 资金管理与仓位规则

## R — 原文 (Reading)

> "通过你自己的观察和研究，不断累积经验，将自己每次入场获胜的概率从50％提高到60％，甚至70％；而且每次进场不要下注太大，应只是本金的小部分。这样长期下来，你就能'久赌必赢'。"
>
> — 陈江挺《炒股的智慧》第三章第二节"提高获胜概率"

> "新手的话，把本金分成6～8份，每次下其中一份。有了经验，慢慢地把份数减少。你如果有60％的胜算，下注的数额比你有80％的胜算时应该为少。"
>
> — 陈江挺《炒股的智慧》第三章第二节"提高获胜概率"

---

## I — 方法论骨架 (Interpretation)

1. 本卡回答每笔交易的两个下注问题：这场赌局值不值得进（胜算是否>50%），以及这一注下多大（占本金多少）。
2. 数学出发点有两条：亏50%要赚100%才能回本（亏损非对称→"亏小钱"优先于一切）；抛硬币例说明胜率不变时，注额从本金的1/1000升到1/2，游戏性质就从"赢定"变成"可能输光"——决定生死的是注额占比，不只是概率本身。
3. 保本（"败而不倒"的执行层）只有两法：快速止损＋别一次下注太多；后者落地为份数与分批规则。
4. 份数与胜算联动：新手把本金分成6~8份、每注一份；有经验后份数渐减；60%胜算下约10%的注，80%胜算可加到30%~50%；有疑问时胜算只剩50%——离场。
5. 开仓门槛（家训"分散风险"）：本金分5~10份，在至少1:3的风险报酬比时才投其中一份入市。
6. 分层下注：预备买1000股先买200股试盘，运动符合预想再进400股，又理想才买足——加码的合法性来自"判断被验证/纸面有利润"；利物莫金字塔：只在升势加码、每手价格高于上一手、首手无利润不加第二手。
7. 组合约束：持股3~5只起步、极限自设（作者20只）；每手不超本金10%（2016年再版操作建议的风险条目）。
8. 动态调节：睡眠测试（担忧到睡不着＝风险超承受力，减仓到睡得好为止）；严禁向下摊平——"摊平=解套良方"只对充分分散的基金成立，对个股是破产捷径。
9. 终极底线：任何时候不输光，输光了游戏就结束。原书只给"胜率×小注"的思想与区间规则，没有凯利公式类的最优注额计算——本卡照实执行，不补造公式。

## A1 — 应用示例 (Application Example)

### 示例 1: 抛硬币赌局——注额改变游戏性质
- **类型与来源**: 原书例题（worked_example），第三章第二节"提高获胜概率"。
- **问题/输入**: 抛硬币正反各50%，本金1000元。赔率设置A：正面你赢0.95元、反面你输1元——你拒赌；赔率设置B：正面赢1元、反面输0.95元——你抢着赌（优势比1∶0.95）。再把每注从本金的1/1000（1元）提高到1/2（500元，赢500/输475）。
- **方法论的使用**: 概率与优势都没变，变的只是注额占本金的比例；每注500元时1000元本金只够赌两回，"赢定的感觉没有了"。
- **结论**: 长期输赢由"胜率×注额占比"共同决定；正期望游戏配大注仍会输光，配小注才能久赌必赢。
- **结果**: 原书为结论性陈述；同节佐证：赌场每局优势仅1%～2%仍稳赚（靠小注×次数），而带2000美元的赌客因每注太大通常不到半小时输光（原书观察性转述）。

### 示例 2: 分层下注——1000股分三批（200/400/400）
- **类型与来源**: 原书例题（worked_example），第三章第一节"保本"。
- **问题/输入**: 预备买1000股某只股票，第一手该买多少？
- **方法论的使用**: 先买200股试盘，看运动是否符合预想；不对则尽快止损；一切正常再进400股；结果又理想才买足1000股。
- **结论**: 错时损失被锁在第一手小注，对时才逐级投入大注；加码前提是"纸面有利润＝判断被验证"，与向下摊平方向严格相反。
- **结果**: 原书为方法陈述，并配分散演算佐证：10000元分投10只、5跌10%/4升10%/1升200%→11900元（近20%回报），决定性因素是那只升200%的股票（原书演算）。

### 示例 3: 正常运动的仓位含义（20→27→24→35）
- **类型与来源**: 原书例题（worked_example，第三章第二节"抓住正常运动中的股票"图3-1），衔接第三章第一节"赚大钱"的胜算-仓位规则。
- **问题/输入**: 股票从20元放量升至27元，缩量回调到24元，再度放量冲破35元（原书称此后应很容易直冲45～50元）。
- **方法论的使用**: 量价序列判定运动正常（正常回调绝不被吓出场）→ 原书衔接句："如果你确定股票运动正常，你的胜算很大，这时你应该在这只股票上适当加大下注的比重"；规则化为制胜概率60%下10%的注、80%时加到30%甚至50%。
- **结论**: 运动正常性判定的结论是胜算自估的主要输入，直接决定注额档位——"下注的数额和下注的时机也有密切的关系"，分析与仓位在此闭环。
- **结果**: 原书为规则与例题衔接陈述，未给出具体注额演算（如实标注）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 已决定买入某股，问"这笔该投多少钱/买多少股/上多大仓位"。
2. 问"怎么分批建仓、什么时候加仓、加多少、能不能补仓摊低成本"。
3. 问"我该拿多少资金进股市、同时拿几只股票合适"。
4. 自评"这次胜算很大"，问能不能重仓一把甚至豪赌。
5. 持仓到失眠、心态不稳，怀疑是不是仓位太重。

### 语言信号 (用户的话里出现这些就应激活)

- "仓位""下注/买多少""几成仓""分几批买""加仓/金字塔加码"
- "风险报酬比划不划算""值不值得博""赔率/胜算"
- "补仓""摊平""拉低成本"
- "睡不好/拿不稳/心慌是不是仓位重了"
- "融资""两融""杠杆""加倍下注该不该"（按风险-胜算原则与书中反面案例作答，杠杆不放大大势风险）
- "position sizing""money management""仓位管理""资金管理"

### 与相邻 skill 的区分

- 与 `critical-point-buy-skill`/`sell-trailing-stop-skill` 的区别: 那两卡回答"买卖位置"（在哪买、在哪卖），本卡回答"仓位大小"（买多少、怎么分批与加码）。同一笔交易的完整决策＝位置＋仓位；止损价由买点卡给出后作为本卡风险计算的输入。
- 与 `return-allocation` 的区别: 对方是资产配置战略层（多大比例资金入市、股债/基金/现金怎么摆、合理回报预期），本卡是单笔交易执行层（每一注多大、怎么分仓加码）。
- 与 `ma250-system` 的区别: 对方的"每手不超本金10%"只是本卡众多仓位规则中的一条（该简易系统专属上限）；本卡是覆盖份数、胜算联动、1:3门槛、分层下注、摊平禁令、睡眠测试的完整仓位体系。
- 与 `psych-discipline` 的区别: "情绪性加码"的自检与计划纪律在对方卡；本卡给可计算的仓位规则本体（计划内加仓才合法）。

## E — 可执行步骤 (Execution)

**必需输入**: ①本金总额（余钱口径；先自答"我亏得起吗"）；②经验水平（新手/有经验）与本次胜算自评p（主观估计，原书无客观公式）；③拟交易个股的买入价与止损价（来自临界点买点决策的输出）、目标参照价（前高/阻力线等图形参照，原书未给目标价算法）；④现有持仓（只数与各笔规模）。缺失本金、买入价或止损价任一项 → 先询问，不得静默猜值。

**交付物与完成标准**: 仓位计划 = 分几批/每批股数与金额（A股按100股整手取整为执行适配，需注明）/每批验证条件与止损价 ＋ 本笔投入占本金比 ＋ 最大亏损额（＝每股风险×股数；原书未计手续费等费用，注明）＋ 持股集中度核对。所有数字须通过份数口径、胜算档位、1:3门槛三重核对；不代入了凯利公式或其他最优注额公式（原书未提供，只有思想与区间规则）。

当 skill 被激活后, agent 应按以下步骤执行:

1. **资格检查（判停）**
   - 问"我亏得起吗？"：这笔钱亏光会影响生活（饭钱/房贷/学费/退休钱）→ 流程终止，不入场。
   - 对这只股票的走势有疑问（说不清升跌、搞不清处在什么势）→ 胜算只剩50% → 离场/别买，流程终止。
   - 完成标准: 两项各给出"通过/终止"结论。

2. **确定份数与单注档位**
   - 新手：本金分6~8份，每注一份；有经验后份数渐减。家训另一口径为5~10份、2016再版系统为单笔≤本金10%——三个口径并存呈现，实操可取交集（如10万本金→单笔0.8~1万），不得擅自统一。
   - 胜算-仓位对应规则：p≈60% → 单注≈本金10%；p≈80% → 可加至30%~50%；p<60%按更小注；说不清p → 回到步骤1判停。
   - 完成标准: 单注金额区间唯一确定。

3. **风险报酬比门槛（判停）**
   - 计算每股风险 L＝买入价−止损价；目标盈利 G＝目标参照价−买入价（目标参照必须来自图形结构如前高/阻力线，不可凭空画目标）。
   - G/L<3 → 放弃这笔交易或另选标的，流程终止。
   - 完成标准: 给出 G、L 与比值。

4. **分层建仓序列**
   - 把目标仓位按 200:400:400 的三批比例展开（对应原书1000股例）；第一批试仓 → 验证股价运动符合预想 → 第二批 → 再验证 → 补足；任一批不符合预想 → 立即止损离场，剩余批次作废。
   - 加码合法性：纸面有利润才可加码；只在升势中加码且每手价格高于上一手；首手无利润绝不加第二手。
   - 完成标准: 输出每批的股数/金额、验证条件与止损价。

5. **组合与动态调节**
   - 持股只数：新手3~5只，进阶10~15只，不超自设极限（作者20只）；手头股票太多＝注意力分散、失去对单独股票的感觉。
   - 睡眠测试：持仓到失眠 → 卖一部分直到睡得好；因仓位小而懊悔"买少了" → 识别为加注诱惑，不行动。
   - 亏损单：严禁向下摊平（摊平只对充分分散、跟随大市的基金成立）；唯一例外＝升势中正常下调结束回头时加码，需三五年经验且动机是"知道升势还在"——新手一律禁止。
   - 完成标准: 组合层面给出只数核对与"减仓/不动"结论。

6. **输出仓位计划**（字段见交付物）
   - 完成标准: 四项核对齐备——单注≤份数口径、G/L≥3、分批含验证条件、最大亏损可计算。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问"在哪买/在哪卖"——买卖位置归临界点买点卡与卖点卡（本卡消费它们的止损价输出）。
- 问"该拿多少钱炒股、股债基金怎么配、合理回报多少"——资产配置战略层。
- 要求计算"最优仓位公式"（凯利类）——原书只有思想与区间规则，没有公式；本卡不得补造。
- 没有止损价的交易计划——没有止损价就无法计算风险与1:3比值，本卡拒绝输出仓位数字。

### 作者在书中警告的失败模式

- 向下摊平＝破产的捷径：上海石化1997年45美元一路跌到10美元越摊越深；王安电脑"10次摊平都对…第11次"（该公司已破产）；巴林银行同段引证。
- 一次下注太大：硬币例注额升到本金1/2，"赢定的感觉没有了"；带2000美元的赌客半小时光头；利物莫一生破产三次，根源是注下得太大。
- 满仓不留现金：一般股民几乎把入市资金全部买入股票、"一注都不肯放过"——空仓也是仓位，不符合入场条件就持币等待。
- 情绪性加码：300股赚钱后兴奋加到3000股，跌1元由赚1500变倒亏1800（原书演算）——计划内加仓才合法。
- 手手豪赌："手手下大注，梦想快快发财，那你迟早会翻船说再见"；"财不入急门"。

### 作者的盲点 / 时代局限

- 胜算自评完全主观，"个人胜率能稳定达60%~70%"仅作者自述，无样本量与对照（幸存者偏差：作者自己引用的减肥2%成功率恰是反证）。
- "久赌必赢"隐含每注独立、不计手续费/滑点/税负与连续亏损下的执行变形；亏50%需赚100%的演算同样未计费用，实际回本更难。
- 三个份数口径并存（6~8份/5~10份/单笔≤10%）；另有"承受力大→2~3只＋25%止损"与第四章止损硬顶20%的数值冲突（阶段1.5对该条记needs_review）——呈现时并列，不得擅自统一。
- A股100股整手取整、T+1与涨跌停使小资金分批执行有摩擦，属执行适配层，非原书内容。
- 回报与购买力语境基于美股经验，直接套用到其他市场需先取数校准。

### 容易混淆的邻近方法论

- `return-allocation`：战略配置层 vs 本卡的单笔交易层。
- `ma250-system`：其"每手≤10%"只是本卡规则之一，不能反向把本卡简化成该系统。
- `psych-discipline`：情绪性加码禁令的自检清单在对方，仓位规则本体在本卡。
- `critical-point-buy-skill`：止损价是本卡风险计算 L 的输入，来自买点卡；两卡须联合使用。
