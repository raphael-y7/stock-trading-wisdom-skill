# 股票运动正常性判定

## R — 原文 (Reading)

> "把握股票走势最关键的是，判断股票是否处于正常运动状态。……在正常的升势中，每个波浪的最高点应较上个波浪的最高点为高，最低点也应较上个最低点为高，整个股价的运动应该在走势线之上。"
>
> — 陈江挺《炒股的智慧》第二章第二节"技术分析的基本知识·股票的正常运动"

> "见到危险信号，不要三心二意，不要存有幻想，把股票全部脱手。几天以后，也许一切又恢复正常，你一样可以重新入场。"
>
> — 陈江挺《炒股的智慧》第三章第二节"注意危险信号"

---

## I — 方法论骨架 (Interpretation)

这张卡把"该不该继续持有"从情绪问题变成一张可勾选的体检单。作者的观察是：健康升势不是"一直在涨"，而是"前进两步、退后一步"的节律——上冲放量、回调缩量、回调后收复失地并创新高。判定一只股票运动是否正常，用四个图形维度逐一核对：

1. **走势线**：正常升势须一浪高过一浪（波峰波谷逐级抬高），整体运行在升势线之上；跌势相反。
2. **支撑阻力**：突破阻力线后回调不应跌回阻力线之下；跌破支撑线后若立即弹回，反而可能是买点信号。
3. **双肩头肩**：穿越形态突破点后应当延续，否则不正常。
4. **均线**：正常升势股价应在200天均线上方波动，跌势在下方（作者日常口径用200天）。

四维之上再叠加量价验证：升时放量、回调缩量、收复失地放量创新高、每次上冲强度不弱于上一轮。

全部通过＝正常运动 → 持有安坐不动（这是"让利润奔跑"的执行前提）；任一破坏＝不正常＝危险信号 → 按"上升潜力必须大过下跌可能"的持仓信条全部离场，几天后运动恢复正常可重新入场。判定对象是形态语义（是否符合趋势定义），不是涨跌幅度——"涨得多"不是卖出理由，"跌破了"才是。

## A1 — 应用示例 (Application Example)

### 示例 1: 20→27→24→35 正常升势量价例题

- **类型与来源**: 原书例题（作者教学例证）+ 图3-1，《第三章第二节"抓住正常运动中的股票"》
- **问题/输入**: 假设股票准备从20元升到50元。20元时交易量增至平时一两倍，股价 20→21→22→27；27元升势停顿，回调 27→26→24，期间交易量显著少于上冲段；24元徘徊几天后重新放量上升 24→25→27→35；冲破35元后重复同构回调。
- **方法论的使用**: 四维核对——波峰波谷逐级抬高✓、未跌破任何支撑✓、运行于走势线之上✓、站上均线✓；量价核对——上冲放量✓、回调缩量✓、收复创新高✓、上冲强度逐次增强（"再次冲破35元时，应很容易地直冲到45元或50元"）✓。
- **结论**: 正常运动。回调属正常获利回吐，"千万不要在这个时候将股票卖掉"，专业炒手绝不能在正常回调时被吓出场。
- **结果**: 原书教学例题，未交代实际交易结果。

### 示例 2: 50→55→62→58→64→61 危险信号例题

- **类型与来源**: 原书例题 + 图3-2，《第三章第二节"注意危险信号"》
- **问题/输入**: 股票缓升途中突然狂涨：第一天 50→55 元，第二天 55→62 元（两日交易量突然大增），第二天收盘前半小时从62元跌回58元收盘；第三天开盘强劲冲到64元，第四天跌回61元。
- **方法论的使用**: "大起大落"是正常升势中没有发生过的 → 不正常 → 危险信号亮起 → 按持仓信条（此时获胜概率已不超出50%）→ 不要三心二意，全部脱手。机理：大户吸足筹码后制造暴升吸引散户接货。
- **结论**: 危险信号成立，全部离场；几天后若运动恢复正常可重新入场。边界：不正常≠必跌（"也许暴升的理由是公司真的发明了长生不老药"），离场逻辑是胜算回落，不是预测后市。
- **结果**: 原书例题，未交代该例后续实际涨跌结果。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 已持有某股，纠结"还能不能拿 / 要不要止盈或离场"，并能提供近期K线或量价描述；
2. 持仓股出现异动（放量长上影、暴升后回落、跌破支撑/均线、破位），问"这是洗盘还是出货"；
3. 复盘时想对持仓股做一次"走势健康检查"，确认趋势定义是否仍然成立；
4. 用户描述持股后"回调了，纸上利润在缩水"，在卖与不卖间摇摆（新手把正常回调当出货的高频错误）。

### 语言信号 (用户的话里出现这些就应激活)

- "还能拿吗""要不要卖""止盈还是继续持有""是不是要调整了"
- "洗盘还是出货""放量下跌""破位了""跌破20日线/年线了""危险信号"
- "走势还正常吗""趋势坏了吗"
- 英文: "is this a normal pullback" / "should I hold or exit" / "distribution or washout"

### 与相邻 skill 的区分（初稿，阶段 3 回填定稿）

- 与 `sell-trailing-stop-skill` 的区别: 本卡回答"当前走势是否健康、该不该继续持有"——危险信号触发离场的判定在这里；具体卖点怎么定、有利润后止损怎么上移（操作层）在对方。
- 与 `cycle-phase` 的区别: 本卡是日线级健康检查（四图形+量价）；对方回答处在蓄劲/爬坡/疲劳/下坡哪个大周期位置（月线级阶段定位与各阶段操作许可）。
- 与 `market-regime-skill` 的区别: 本卡对象是单只个股；对方判定指数大市方向（"大市不好别买任何股票"的否决级前提）。

## E — 可执行步骤 (Execution)

**必需输入**: 现价与近期K线序列（至少覆盖最近2–3个波峰波谷）；各波峰/波谷价位；支撑线/阻力线价位（及颈线，如适用）；200天均线值（作者口径；250天线版转 `ma250-system`）；上冲段与回调段的成交量对比（相对均量倍数）。以上缺失（尤其波峰波谷价位、支撑阻力位、量能数据）时先向用户询问，不得静默猜值。

**交付物与完成标准**: 结论三选一（正常→持有 / 异常→离场 / 无势→观望），附四维+量价逐项核对表与触发价格；离场时给出危险信号触发价与重入观察条件。四维每一项必须有"通过/破坏"的明确判定，结论与判定一致；不得只给方向不给依据。

当 skill 被激活后，按以下步骤执行：

1. **确认趋势方向**
   - 完成标准: 依据波峰波谷序列标注升势 / 跌势 / 无势。
   - 判停条件: 若为无势（区间漫无目的游动）→ 输出"无势不炒"，流程终止；若为明确跌势 → 输出离场建议并转 `sell-trailing-stop-skill`，流程终止。

2. **四维逐项核对**（任一破坏即标记"不正常"）
   - 完成标准: ①走势线（波峰波谷逐级抬高、运行于走势线之上）②支撑阻力（突破阻力线后回调未跌回阻力线下；跌破支撑线后是否立即收复）③双肩头肩（穿越突破点后是否延续）④均线（升势中股价在200天线上方；200天线下方原则上不买不持，做短线时例外）——四项各给出"通过/破坏"。

3. **量价验证**
   - 完成标准: 上冲是否放量（可为平时一两倍）、回调是否显著缩量、收复失地是否放量创新高、上冲强度是否不弱于上一轮——逐项核对并记录。

4. **危险信号快检（判停分支）**
   - 判停条件: 缓升途中突然暴升 + 交易量猛增 + 冲高大幅回落（如62元尾盘半小时跌回58元收盘）→ 直接判危险信号 → 执行步骤5的离场动作，跳过综合判定。
   - 完成标准: 有异动时逐条比对危险信号组合并记录命中项；无异动则记"未触发"。

5. **综合判定与动作**
   - 四维+量价全过且无危险信号 → 结论"正常运动"，动作=持有安坐不动（加注提示转 `money-management-skill`）。
   - 任一维度破坏或危险信号成立 → 按"上升潜力必须大过下跌可能"信条，动作=全部脱手、不讨价还价。
   - 完成标准: 结论唯一且与核对表一致；离场时输出触发信号的具体价格。

6. **离场后重入观察（仅离场分支）**
   - 完成标准: 记录重入条件"几天后运动恢复正常（四维+量价重新达标）→ 可重新入场"；并提示迟疑风险——迟疑期间股票继续跌时，勿把下跌路上的喘息当反转。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 没有图形与量价数据、只有基本面消息或新闻时——本卡全部判据建立在走势与成交量之上，此时应先取数或转基本面审视，不猜值判定。
- 问的是"这只股票处在周期哪个阶段"（月线级定位）→ 用 `cycle-phase`；问的是指数大市 → 用 `market-regime-skill`；问"买什么股票" → 用 `stock-picking-skill`。
- 用户只想执行机械均线规则、不读图形 → 用 `ma250-system`（2016再版最小系统）。
- 短线做T、日内博弈——作者口径是日线级趋势判断（均线用200天/50天），非日内框架。

### 作者在书中警告的失败模式

- 把正常回调当出货："入场后开始有利润了，每次回调都意味着纸上利润的减少，常人的第一感觉就是赶快卖掉获利，这是新手的显著特点"——20→27→24 例中作者明令正常回调时千万不要卖掉。
- 危险信号前三心二意、存有幻想：发誓"反弹就走"，反弹来了又觉得"正常"了——"通常，这样的反弹仅是股票在下跌路上的喘息"。
- 指标"见光死"：作者自述学股第二年花了很多学费才明白 MACD 等电脑指标人人照做即失效——本卡只用四个图形+量价，不接入其他指标。

### 作者的盲点 / 时代局限（阶段 0 批判）

- 幸存者偏差：判定基准全部来自作者个人经验（"我碰到十次有九次赚钱"式自述），无样本量、无基准对照。
- 图形有效性在量化时代存疑：作者自认电脑交易冲击下"答案可不容易做"；A股涨跌停与T+1改变突破、回调与止损的微观结构，量能倍数口径需按A股实际重估。
- "正常运动"判定含主观成分：走势线画法、波峰波谷的划分原书未给统一定义，同一图形两人可能判出不同结论。
- 危险信号≠必跌（原书明示可能真有利好），离场逻辑是"胜算回落到50%"——本卡输出是纪律动作，不构成对后市涨跌的预测。

### 容易混淆的邻近方法论

- `cycle-phase`（周期四阶段定位）、`sell-trailing-stop-skill`（卖点与移动止损）、`market-regime-skill`（大市判定）：见 A2 区分。
- 大户操纵痕迹识别（假跌破=恐慌吸纳、假突破=诱多）：为危险信号与异常波动提供机制解释，可与本卡联用；但揣测大户动机不是本卡的判定依据，本卡只认可观察的量价形态。
