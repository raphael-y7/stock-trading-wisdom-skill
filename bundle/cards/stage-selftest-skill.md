# 学股阶段自测与排障

## R — 原文 (Reading)

> "这个阶段的特点是自己没有什么主意，买时不知为何买股票，卖时也不知为何卖。买卖的决定完全由他人或自己的一时冲动所左右。如某某股评家推荐买这只股票，他认为这只股票最少还会升10点等。卖时也没有章法，觉得有钱赚就可以卖了。在这个时期是绝不肯止损的。"
>
> — 陈江挺《炒股的智慧》第八章第一节"学股的四个阶段·蛮干阶段"

---

## I — 方法论骨架 (Interpretation)

1. 本卡回答"我学到什么地步了"：作者按**行为症状**（而不是知识多少、股龄长短）把学股者归入四个阶段——蛮干、摸索、体验风险、"久赌必赢"，每个阶段有明确的症状清单和对应的训练重点。
2. 蛮干阶段：买卖由他人或一时冲动决定；两个典型症状是"不贪"（赚一点就卖）和"不怕"（套牢不卖、等反弹），恰好与该做的相反（该让利润跑、该止损）；这个时期绝不肯止损。作者观察80%以上的股民无法从这个阶段毕业。
3. 摸索阶段：已经知道要止损、要让利润奔跑，但用10%/20%这类机械数字定止损、常把止损位下移；规则时灵时不灵，不知为何赚为何亏；没有系统的买卖点，还在用直觉加"应该不会错"交易。
4. 体验风险阶段：必须亏过一两次吃不下睡不着的大钱，才会真正明白行规的分量；此后"每次赚了大钱，随即常常来一次亏大钱"，因为赚了大钱就觉得自己"懂了"，用希望取代了分析。
5. "久赌必赢"阶段：对盈亏没有情绪波动，知道为何赚、有计划重复赚钱，用概率评估一切因素，凭直觉抓住临界点并熟练运用所有规则——这是学股的里程碑。
6. 时间预期约5-6年、不可跳级；最花时间的是学着找临界点。作者的对应观察："业余炒手因大亏损而破产，专业炒手因获小利而破产。"
7. 对策按阶段对号：蛮干先学止损、小注真金白银地学（纸上交易无用）；摸索专攻临界点、止损挂结构位只上移不下移；体验风险后重读资金管理、别放弃；久赌必赢则维持计划等待大机会。
8. 辅助规则：方法必须匹配个性与市场——每种方法只在特定市场有效，跌势和震荡市应减仓或离场而不是临时换方法；持之以恒，任何时候都必须有方法且照办。

## A1 — 应用示例 (Application Example)

### 示例 1: 作者自述的四阶段历程（阶段定位的活样板）
- **类型与来源**: 作者亲历自述（第八章第一节"学股的四个阶段"全节；案例验证 c80–c84；作者自述无第三方佐证，引用时保留该限定）。
- **问题/输入**: 作者如何经历并判定自己的四个阶段、每次升级的判据是什么。
- **方法论的使用（按阶段拆解）**:
  1. 蛮干——约半年，因初始者好运居然赚到钱，"对自己的悟性有了极大的信心"；
  2. 摸索——先定"跌1美元就卖"，结果"小损终于加成大损"；放宽到10%再20%，常是亏时27美元卖、赚时31.5美元出场（亏3赚1.5），还把止损从27下移到26或25（"我知道这样做不对，但我忍不住"）；试遍基本面、技术分析、电脑指标"没有一样有效"，专职近四年白干还亏了老本；
  3. 体验风险——期货上悟到走势/阻力/支撑概念、"灵光闪耀"之后，两周亏掉53000美元（按其规则极限只应亏4000左右——注下得太大又不肯止损，"我用希望取代了分析"）；
  4. 久赌必赢——此后两年完全按整理出的规则执行，年回报超过100%且在极小的风险下取得（作者自述）。
- **结论**: 阶段判定＝行为对号入座，不是知识测验；升级判据分别是"知道蛮干不对""亏过大钱才懂行规""盈亏不再带动情绪"。作者全程近六年，四阶段不可跳级。
- **结果**: 如上（作者自述实录；其年回报数字为个人陈述，无样本统计）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 学股一段时间后自问"我算入门了吗""我现在处于什么水平""还要多久才能稳定盈利"。
2. 反复出现同一类错误（赚点就跑、套牢不卖、止损总被洗出），想弄清这是不是阶段性的必经问题、该先练什么。
3. 刚经历一次大亏（或一次大赚后马上大亏），想知道这在学习路径中意味着什么、下一步怎么走。
4. 在几套方法之间来回切换总觉得"都不灵"，怀疑是方法问题还是自己问题。
5. 准备投入更多资金或时间学炒股前，想校准预期（要交多少学费、花多少年）。

### 语言信号 (用户的话里出现这些就应激活)

- "我算什么水平""在哪个阶段""学股要学几年""怎样才能毕业/入门"
- "为什么我总是止损止不好""刚买就卖、套牢就不动""不知道为什么赚为什么亏"
- "该先学什么""从哪里开始练""新手学炒股的路径""learning stages / am I still a novice / how long to get good"

### 与相邻 skill 的区分

- 与 `psych-discipline`（心理纪律执行清单）的区别: 对方查**当下这笔交易**的执行纪律（有没有照规则做），输出违规项；本卡定位**学习阶段与训练路径**（阶段性能力问题）。复盘发现违规是系统性的、不是疏忽时，转本卡。
- 与 `money-management-skill` 等操作卡的区别: 对方给某类规则本体；本卡不给任何操作规则，只输出"阶段+该阶段训练重点+典型错误对策"，具体规则引用对应操作卡。
- 本卡不用于个股分析决策：不判断某只股票该不该买卖、不评估股评推荐，只服务于投资者的自我评估与学习路径。

## E — 可执行步骤 (Execution)

**必需输入**: 用户对自身交易行为的描述——①怎么决定买卖（自己研究/听推荐/一时冲动）；②怎么止损（有没有止损位、机械百分比还是结构位、是否常下移）；③赚钱单与亏钱单怎么处理（落袋快慢、是否死扛）；④有无亏过大钱的经历及当时的反应；⑤股龄与投入资金性质。只有"我觉得自己还行"这类自我评价而无行为细节时先询问，不得凭股龄或资金量直接判定阶段。

**交付物与完成标准**: 阶段判定（蛮干/摸索/体验风险/"久赌必赢"之一，相邻交错时如实注明）＋该阶段训练重点＋典型错误对策清单（每条可回溯原书规则）＋时间预期声明（约5-6年、不可跳级、"80%以上无法毕业"为作者观察）。不输出个股建议，不输出仓位计算。

当 skill 被激活后, agent 应按以下步骤执行:

1. **四阶段症状问卷（逐项核对，输出命中/未命中＋行为证据）**
   - 蛮干: 买卖由他人或冲动决定？赚一点就卖？套牢不卖等反弹？绝不肯止损？
   - 摸索: 用10%/20%等机械数字定止损？常把止损位下移？规则时灵时不灵？不知为何赚为何亏？无系统买卖点、靠直觉加"应该不会错"？
   - 体验风险: 亏过吃不下睡不着的大钱？亏后真正反思过行规？"赚大钱随即亏大钱"是否重复出现？
   - "久赌必赢": 对盈亏无情绪波动？知道为何赚为何亏？有计划重复赚钱？用概率评估大市/估值/升势/正常运动等因素？
   - 完成标准: 每阶段给出命中/未命中＋一句行为证据。

2. **判定主阶段**
   - 判停条件: 蛮干两症状（赚点就卖＋套牢不卖）俱在 → 判蛮干，输出"学股的道路还很漫长"并跳到步骤3的蛮干对策。
   - 否则按命中证据最多的阶段判定；原书自述"阶段划分并不严格，很多时候互相交错"，相邻并存时如实标注。
   - 完成标准: 输出唯一主阶段＋判定证据；无法判定时列出缺口信息向用户追问。

3. **对策映射（按阶段，只引原书规则，不补造）**
   - 蛮干 → 先学止损（家训1"止损，止损，止损"是最高行为准则）；小注分仓；必须用真钱小注学——"不把钱投入，你不会经历恐惧、贪婪、希望等心理过程"（纸上交易无用）。
   - 摸索 → 最花时间的是学找临界点（第四章买点八要点+临界点心理脉络）；止损挂结构位（入市日最低点/支撑线略下）而非机械数字，且只上移不下移；方法-个性-市场匹配、持之以恒——跌势和震荡市减仓或离场，而不是换方法。
   - 体验风险 → 重读第三章第二节"资金管理"，把每注缩到止损极限内；"亏大钱常常是大成之前的最后考验，请千万不要放弃"。
   - "久赌必赢" → 维持既定计划；用概率加分清单评估入场；等待大机会（可遇不可求）。
   - 完成标准: 每条对策注明原书出处章节；无出处的建议一律不写。

4. **预期与路径声明**
   - 声明约5-6年、不可跳级、"最花时间的是怎么学着找临界点"；提示华尔街名言"业余炒手因大亏损而破产，专业炒手因获小利而破产"——训练须同时覆盖止损与让利润奔跑两端。
   - 完成标准: 输出末尾含预期声明；四件套（阶段/训练重点/对策/预期）齐备。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问的是某只股票的分析与买卖决策——本卡不接触任何个股。
- 问的是当下某笔交易的纪律违规——用心理纪律执行清单逐条核对。
- 问的是具体规则（止损设哪、仓位多大）——直接用对应操作卡，本卡只做阶段映射。
- 用户期待"快速晋级"的捷径承诺——原书明确"寻找临界点没有捷径，只有实验、失败、再实验"。

### 作者在书中警告的失败模式

- 初始者运气：蛮干半年赚钱导致信心爆棚——"这些钱是股市暂时'借'给你的，迟早会收回去，不信的话你就等3年看看"（前言）。
- 聪明人专职失败：不下10位硕博朋友学专职炒股毫无例外只生存了几个月——"他们太聪明，选择太多"（第一章）。
- 频繁换方法死循环：方法在跌势/震荡市失效就换方法，几个循环下来即被淘汰（第四章第三节）。
- 纸上交易无用论：模拟盘不经历恐惧贪婪希望，"你在浪费时间"（第八章问答）。
- 体验风险阶段的自毁："每次赚了大钱，随即常常来一次亏大钱"——作者两周亏53000美元即发生在此阶段（第八章）。

### 作者的盲点 / 时代局限

- "5-6年毕业"与"80%以上股民无法毕业"均为作者个人观察，无样本统计，且属幸存者样本；不可当作承诺或精确预测。
- 阶段边界模糊、相邻阶段可并存（作者自己承认"划分并不严格"）；"年回报超100%"为个人自述，无第三方佐证。
- 四阶段基于美股1980-90年代环境；A股的交易成本、涨跌停与信息环境不同，各阶段时长会不同，但症状分类本身与市场无关。

### 容易混淆的邻近方法论

- `psych-discipline`：纪律审计（当下执行）vs 阶段定位（长期路径），复盘时先查纪律、再定阶段。
- "薄→厚→薄"学习路径（第二章第三节）：学习理念参考，无阶段判定输出，不单独执行。
- 方法-个性-市场匹配（第四章第三节）：本卡的辅助规则之一，不独立成方法。
