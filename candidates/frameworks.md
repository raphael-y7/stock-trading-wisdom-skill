  title: 概率思维模型（炒股是艺术不是科学）
  type: mental-model
  source_chapter: 第一章第三节
  source_quote: |
    "炒股有个很特别的地方:炒股是艺术，不是科学。科学要求能够重复，股价的变动从不重复，最多只有百分之多少相像！
    ……重新学习一种思维方式，用哲学和艺术的思维方式来面对不确定加上应用概率分析的思考方式应对之并不如想象中那么容易。"
  summary: |
    输入：任何股价预测与分析问题。判断前提：股价从不完全重复，无法用科学（可重复实验）方法找到确定答案。
    步骤：放弃"找重复规律"的科学式思路，转为概率式思考——承认任何买卖决定都没有100%对错，唯一能做的是把每次入场的获胜概率从50%提到60%甚至70%；对"指标/公式/绝招"类确定性承诺保持警惕（作者称各类电脑指标"见光死"）。
    输出：以"胜算是否超过50%"作为每个决策的衡量标尺，而非"对错"标尺；接受不确定性并坦然执行止损。这是全书所有买卖机制的元模型。

- id: f03
  title: 股票运动正常性判定（四维+量价）
  type: framework
  source_chapter: 第二章第二节（另见第三章第二节"抓住正常运动中的股票"）
  source_quote: |
    "把握股票走势最关键的是，判断股票是否处于正常运动状态。……在正常的升势中，每个波浪的最高点应较上个波浪的最高点为高，
    最低点也应较上个最低点为高，整个股价的运动应该在走势线之上。……一个正常的升势，股价应在200天平均线之上……否则，都可以认为是不正常运动。"
  summary: |
    输入：个股的K线走势、成交量、关键价位、均线位置。判断条件（四个维度逐一核对）：
    ①走势线——正常升势须一浪高过一浪（高点抬高、低点抬高）且运行于升势线之上，跌势相反；
    ②支撑阻力——阻力线被突破后回调不应跌回阻力线之下，支撑线跌破后应继续下跌，否则不正常；跌破支撑线又立即弹回则是买点（见f18）；
    ③突破点确认——穿越双肩/头肩突破点后应能继续，否则不正常；
    ④均线——正常升势股价应在200天（作者日常用）或250天均线上方。
    再叠加量价验证（第三章20→27→24→35元实例）：上冲时交易量增加、获利回吐时量显著减少、回调后收复失地创新高、每次上冲更强。
    输出：正常→持有安坐不动（可加大下注）；不正常→危险信号→离场（接f13）。这是作者自称"把握股票走势最关键"的判断，也是"让利润奔跑"的执行前提。
  tags: [framework, technical-analysis, normality-check, volume-price]

- id: f04
  title: 股票周期四阶段判定（蓄劲/爬坡/疲劳/下坡）
  type: framework
  source_chapter: 第二章第二节（图2-14）
  source_quote: |
    "可以将股票运动大约分成四个时期，分别为蓄劲期、爬坡期、疲劳期和下坡期。蓄劲期:买卖双方的力量基本平衡。爬坡期:买压胜过卖压。
    疲劳期:买压和卖压又基本持平。下坡期:卖压强过买压。……在蓄劲后期，爬坡初期……应有交易量增加的现象，股价一举突破阻力线。"
  summary: |
    输入：个股长期走势图与均线上呈大弧的形态、成交量。判断条件：蓄劲期=区间横盘、买卖力量平衡；爬坡期=放量突破阻力线、一波高过一波、股价站上200天线；疲劳期=高位滞涨、买卖力持平；下坡期=跌穿均线及支撑线、卖压占优。
    步骤：①把股价运动归类到四阶段之一（四阶段吻合经济周期，小公司起伏更剧烈）；②按阶段给操作许可——蓄劲期观望或低位吸纳，蓄劲后期/爬坡初期放量突破阻力线是真升势起点（入场）；爬坡期安坐如山、只盯危险信号；疲劳期警惕；疲劳期后跌穿均线及支撑线即离场；下坡期不碰。
    输出：阶段判定+该阶段的操作许可（买/持/卖/观望）。强调"股市操纵可能改变每天或短期波动，但不可能改变大势"。
  tags: [framework, cycle, stage-location]

- id: f07
  title: 价格与价值的遛狗模型
  type: mental-model
  source_chapter: 第二章第四节
  source_quote: |
    "想象你外出遛狗，狗有时跑在前面，有时跑在后面；你拴狗的绳子也有时长，有时短，但无论如何，狗最终会跑回你身边。
    你就是价值，狗就是价格。体会一下这个例子，你会明白很多东西。太离谱的股价有时会出现，但通常不会维持很久。"
  summary: |
    输入：股价与公司价值的关系问题。判断条件：价值（人）决定长期牵引方向，价格（狗）围绕价值前后偏离，绳子（时间）长短不定。
    步骤：用该模型理解短期价格可以极度偏离价值（泡沫/恐慌），但不离谱的状态不会长久维持；同时认识到现金值法等"合理价位"计算都依赖对通胀与未来盈利的假设，本质是"猜"，只能作参考。
    输出：既不把"股价低于价值"当立即买入理由（狗可以继续跑远），也不对离谱价格恐慌（绳子终会拉回）；价值评估作为长期背景而非买卖触发器。
  tags: [mental-model, valuation]

    输入：股票指数走势、每日交易总量、市场结构数据与情绪。步骤：①每天追踪指数，把它当成一只股票套用f03/f04判定阶段与正常性；②留意交易总量——总量大而指数不升、或开高收低，是危险信号；③六条注意点：大的政治经济环境变动、本国经济大势与利率汇率动向、龙头股是否率先疲软（到顶前兆）、垃圾股/无人问津的小股票是否突然活跃（到顶前兆，游资涌向三四线）、每日涨跌家数（防综合指数被权重股糊弄）、类别股分化（按类别形态定个股买卖）；④顶部信号=街头巷尾谈股市赚钱、人人已投入资金；底部信号=大众恐惧、该卖的已卖完，某天放量大升（大户入场），随后指数突破上一浪高点证实跌势结束才进场。
    输出：大市结论（可全力买/观望/离场）。它是选股三步（f21）的第一道否决闸：逆大市而动，获胜概率大打折扣。

- id: f10
  title: 资金管理/下注框架（胜率×小注=久赌必赢）
  type: framework
  source_chapter: 第三章第二节
  source_quote: |
    "将自己每次入场获胜的概率从50％提高到60％，甚至70％；而且每次进场不要下注太大，应只是本金的小部分。这样长期下来，你就能'久赌必赢'。
    ……新手的话，把本金分成6～8份，每次下其中一份。你如果有60％的胜算，下注的数额比你有80％的胜算时应该为少。"
  summary: |
    输入：本金总额、自身经验与胜率自估。判断条件：硬币例证明——输赢概率不变时，下注额从本金的1/1000升到1/2，游戏性质就从"赢定"变为"可能剃光头"；每次下注只占本金小部分，坏运气就淘汰不了你。
    步骤：①入市前先自问"我亏得起吗？"（败而不倒的前提）；②把本金分成6～8份，每次下一份，有经验后逐步减少份数；③胜率越高注越大（60%胜算的注<80%胜算的注），胜算与仓位联动；④分散风险时在"至少1:3的风险报酬比"的场合才投一份（第五章）；⑤长期用数学期望积累。
    输出：每笔仓位规模与加注规则。亏损的非对称性（亏50%需赚100%回本）是保本优先的数学根据。
  tags: [framework, money-management-skill, position-sizing]

- id: f11
  title: 分层下注试仓操作（含"纸面无利润不加码"）
  type: procedure
  source_chapter: 第三章第一节（另见第五章"不要向下摊平"）
  source_quote: |
    "具体的做法就是分层下注。你如果预备买1000股某只股票，第一手别买1000股，先买200股试试，看看股票的运动是否符合你的预想，
    然后再决定下一步怎么做。如果不对，尽快止损。如果一切正常，再进400股，结果又理想的话，买足1000股。"
  summary: |
    输入：计划买入的目标仓位（如1000股）。步骤：第一手只买小部分（如200股）试市场→验证股价运动是否符合预想→不符合则即刻止损出局；符合则加到400股；再次符合则买足计划仓位。加码的判定条件是"纸面上已有利润"（第五章表述：第一次入场后纸面没有利润就不加码，有利润说明判断正确才扩大战果）。
    输出：风险前置的下注序列——错时损失被限制在第一手小注，对时才逐步投入大注。与"向下摊平"（亏了加码摊低成本，破产捷径）严格相反。
  tags: [procedure, position-sizing, pyramiding]

- id: f13
  title: 危险信号响应机制（不正常即离场，之后可重入）
  type: troubleshooting
  source_chapter: 第三章第二节"注意危险信号"
  source_quote: |
    "在股票缓慢上升的过程中，它自然地升，自然地跌，突然某天大起大落，这是在正常上升过程中没有发生过的。一旦有不正常现象出现……这时的正常做法就是，将股票脱手。
    ……见到危险信号，不要三心二意，不要存有幻想，把股票全部脱手。几天以后，也许一切又恢复正常，你一样可以重新入场。"
  summary: |
    输入：持股期间股价行为突然偏离f03的正常运动模式。症状识别（图3-2实例）：缓升途中突然暴升（50→55→62元）、交易量猛增、次日冲高大幅回落（62跌回58收盘）、随后失去冲劲跌回——大起大落是正常升势中没发生过的，通常是大户吸足筹码后制造暴升吸引散户接货。
    判断条件：不正常信号出现≠股票一定下跌（可能真有利好），但此时获胜概率已不超出50%；持有的基本信条是"上升潜力必须大过下跌可能，否则不留在手里"。
    操作：不加理由、不存幻想，把股票全部脱手（火车来了先闪开，火车过去随时可再上铁道）。
    验证/升级：几天后一切恢复正常可重新入场；若迟疑期间股票又跌，应痛下决心按誓言反弹即走，勿把下跌喘息当反转。
  tags: [troubleshooting, sell-signal, danger-signal]

  type: framework

  title: 善战者无赫赫之功（结硬寨、打呆战的资本战略）
  type: mental-model
  source_chapter: 第九章（章题及第三、四节）
  source_quote: |
    "股市上想一把赚100％，得准备一把亏80％；故善炒股者不试图一把豪赌将本金翻倍，试图在不怎么亏钱的情况下让资本不断增值。
    ……善战者集小胜为大胜，最后完成战略目的。善炒股者集小赢为大赢，最后达成财务自由。"
  summary: |
    输入：长期炒股的战略定位问题。模型：股市之仗打不完且只要败一次就可能前功尽弃（"华尔街没有勇敢的老交易员"），故每一战役都应以最小可能损失推进，不追求一战完功——曾国藩式"结硬寨"（深壕高垒先保不受损失=保本/止损/轻仓）+"打呆战"（不心存侥幸，有多少实力打多大的仗=胜率与注码匹配）。
