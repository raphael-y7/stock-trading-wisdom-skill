# 选股三步过滤

## R — 原文 (Reading)

> "第一，什么是大市的走向？如果大市不好，你最好什么都别买，安坐不动。……第二，哪些类别的股票'牛劲'最足？……第三……在'牛劲'最足的股类中选择一两只'龙头'股。"
>
> — 陈江挺，第四章第一节"选择股票的步骤"

> "被套牢是极其不愉快的经历，晚上睡觉时想到这只股票都睡不好！很多人撑不住就割肉算了。蓄劲期越久，那些被套牢还未割肉的投资者就越少，它上升时的阻力也就越小。"
>
> — 陈江挺，第四章第一节（图4-10/图4-11 说明段）

## I — 方法论骨架 (Interpretation)

选股不是"找一只好股票"，而是三道串联的过滤闸门，把资金最终引向"胜算最大的时刻、胜算最高的股票"。

1. 第一道闸门是大市：大市不好时什么都不买、安坐不动——哪怕看到再吸引人的临界入场点也不动，因为大环境不适合时个人胜算被系统性削低。这一步是否决级的，直接引用大市判定卡的结论作输入。
2. 第二道闸门是类别强度（作者称"牛劲"）：同样技术图形、同样放量进入爬坡的两只股票，属牛劲足类别的轻松升 100%，牛劲不足的辛苦才升 20%——所以先选类别，不先选个股。
3. 第三道闸门是类别内选龙头：在牛劲最足的类别里挑一两只"龙头老大"（板块公认龙头），或"特别小弟"（有特别产品或专利）。
4. 同类候选多于一只时，再按"筹码位置"细分排序：从低位一浪高过一浪爬上来的，优于从高位跌下来横盘的——后者在原阻力位上方积聚大量套牢盘，重回该价位时解套抛压沉重；同为横盘蓄劲，蓄劲期越长套牢盘被磨得越干净，上升阻力越小。
5. 最后是个人纪律：被某只股票"烫"过三次就不再碰它，把注意力放在摸得透个性的股票上。

整个方法把"买什么"从直觉（挑便宜的、听消息）重构为否决式过滤：每一道闸门都在剔除一种降低胜算的选择。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 手上有几只候选股或几个热门板块，不知钱该投到哪：问"现在买什么股票""这几个板块哪个更强"。
2. 同一板块内两只走势相似的股票（都放量、都接近突破）需要二选一。
3. 看到从高点跌下来一半的股票觉得"便宜"想抄底，需要检查套牢盘逻辑。
4. 在某只股票上反复亏损，又想"再给它一次机会"。
5. 已经决定要买（何时买卖交给买点/卖点卡），先要回答"买哪只、买哪类"。

### 语言信号 (用户的话里出现这些就应激活)

- "现在买什么股好？""哪个板块/类别牛？"
- "同板块这两只，选哪只？"
- "它都跌了 50%，够便宜了吧？"
- "这只票我又亏了，要不要再进？"
- "板块里哪只是龙头？" / "which stock to buy" / "which sector is strongest"

### 与相邻 skill 的区分 (初稿，阶段 3 回填定稿)

- 与 `critical-point-buy-skill` 的区别: 本卡回答"买什么股——哪个类别牛劲足、选哪只龙头"；对方回答"何时买——在哪个临界点入场并同步定止损"。本卡产出候选对象，对方接管该对象给出入场触发与止损价。
- 与 `market-regime-skill` 的区别: 本卡是个股/类别选择；对方是指数方向判定。本卡第一步直接引用对方的大市结论作输入，不在本卡内重判大市。
- 与 `fundamental-check` 的区别: 对方是单公司质量定性检查（小环境五项+涨三因素）；本卡是类别强度与筹码位置的筛选，不做单公司财务质量评估。
- 与 `cycle-phase` 的区别: 本卡只在候选股之间比较蓄劲期长短与套牢盘轻重（图4-10/4-11 式的"三个月 vs 半年"对比）；问"这只股票当前算不算蓄劲期/处在哪个阶段"属对方，本卡不做单票阶段判定。

## E — 可执行步骤 (Execution)

**必需输入** (缺失先询问，不能静默猜值):
1. 大市结论（牛/熊/震荡及判定依据；用户未判定时先走 market-regime-skill 卡或请用户提供指数阶段判断）。
2. 候选类别清单（至少 2 个板块及各自近期走势）。
3. 类别内候选个股的走势资料：所处阶段（蓄劲/爬坡/疲劳/下坡）、阻力线位置、是低位爬升还是高位跌落、横盘蓄劲时长。
4. 本人对各候选股的历史交易记录（被"烫"的次数——亏损离场次数）。

**交付物与完成标准**: 输出 = 入选类别 + 1~2 只个股 + 入选理由 + 排除项清单（每只被排除的股票标注触发的排除规则）；完成标准 = 三步各有可核对的书面结论、排除项可追溯到具体规则；"牛劲"比较无量化指标，凡属定性判断须如实注明。

当 skill 被激活后, agent 应按以下步骤执行:

1. **第一步闸门——核对大市结论**
   - 完成标准: 明确写出大市方向及其来源。
   - 判停条件: 若大市不好（或方向不明），直接输出"什么都不买，安坐不动"，流程终止——原书口径：就算看到很吸引人的临界入场点，也不要轻易有所动作。

2. **第二步——类别筛选（比"牛劲"）**
   - 完成标准: 在"同类技术图形 + 充分交易量进入爬坡"的统一口径下，比较候选类别近月表现，排出牛劲最足的 1~2 个类别；比较依据写明（如近月相对强度、突破质量），定性比较须注明。

3. **第三步——类别内选龙头**
   - 完成标准: 在牛劲足类别中列出"龙头老大"（板块公认龙头）或"特别小弟"（有特别产品/专利）候选 1~2 只。

4. **细分排序（同类候选多于一只时执行）**
   - 规则①: 低位一浪高过一浪爬升者优先于高位跌落横盘者（后者阻力位上方套牢盘解套抛压重，突破日假突破概率大增）。
   - 规则②: 同为横盘蓄劲，蓄劲期长者优先（套牢盘被磨得更干净）。
   - 规则③: 本人被烫满三次的股票直接剔除，不再碰。
   - 完成标准: 每只候选按①②③给出排序结论，剔除项注明理由。

5. **汇总输出**
   - 完成标准: 输出"类别 + 个股 + 理由 + 排除项"四要素齐全；入场时机与止损价不在本卡内确定，转 critical-point-buy-skill 卡执行。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只想知道"何时买/在哪买/止损设哪"——那是临界点买点卡的领地，本卡只筛对象不定时点。
- 想对单家公司做经营质量与成长性检查——用基本面快速审视卡，本卡不做单公司财务评估。
- 大盘方向本身还不明、需要判定——先走大市判定卡，本卡第一步只是引用其结论，不重判。
- 手头只有消息面热点、没有板块与个股走势数据——本卡要求图形与类别强度证据；证据不足先补数据，不能按消息选股。

### 作者在书中警告的失败模式

- 听消息/跟风选股：三个盲人带路；理发师、美容师、餐馆跑堂都在谈股票时更危险（原书反例素材）。
- 买"便宜的"高位跌下来的股票：图4-9 直觉陷阱——"跌了很多"不是买入理由，40→20 美元的例子照跌不误。
- 大市不好时因"让钱闲着极其难受"而忍不住乱买：必须学习忍耐。
- 买一大堆股票分散注意力：电话号码才 10 个数字，持股集中 3~5 只、极限 20 只。
- 在"无缘"的股票上重复被烫，违反烫三次不再碰的纪律。

### 作者的盲点 / 时代局限

- "牛劲"与"龙头"均无量化指标，原书靠图形加个人经验比较；龙头识别依赖板块知识，结论主观。
- 幸存者偏差：选股经验来自作者个人自述，无样本量与基准对照。
- "不买高位跌下来的"对周期股困境反转情境可能误杀（原书未讨论）。
- 时代背景为 1980–2005 美股与 1990s 港股庄股生态；A 股涨跌停、T+1 制度改变了突破与套牢盘行为的微观结构。

### 容易混淆的邻近方法论

- 题材/热点轮动追涨: 本卡选的是已确认放量进入爬坡的强势类别，不是追未启动的概念传闻。
- 价值投资"低估值买入": 本卡明确排除"高位跌下来的便宜货"逻辑，两者选股哲学相反。
- 基本面筛选: 原书把公司质量作底层校验（"不知公司干什么的，心里虚"），但选股排序依据是类别强度与筹码位置，不是财务指标。
