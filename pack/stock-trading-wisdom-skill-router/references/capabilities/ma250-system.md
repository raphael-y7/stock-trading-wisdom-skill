# 250天线简易操作系统

## R — 原文 (Reading)

> "1.不管什么股票，买股之前，先看看250天的平均线。只买250天均线以上的股票，最好在股价从250天均线之下穿越到250天均线之上时买入。2.进股后给个5％—8％的止损。3.只要股价在250天均线之上，坐等！……一旦股价再回碰到250天均线，卖掉！4.每手不要下超过本金的10％。"
>
> — 陈江挺《炒股的智慧》"2016年再版的话"（四条具体建议）

---

## I — 方法论骨架 (Interpretation)

这张卡是作者给"大多数读者"的让步: 他明说，按自身风险承受力制订完整操作计划"对大多数读者而言要求太高"，所以直接给一套四要素齐备（进点/止损/卖点/每手风险额）、可以照做的最小系统——不需要读图形、不需要找临界点、不需要判定正常运动。

规则只有四条，外加一条仓位上限:

- 只买250天均线**以上**的股票，最好的买点是股价刚从线下上穿到线上之时；
- 入场后设5%–8%的止损；
- 只要股价在250天线上方就**坐等**（可能几年不回踩）；一旦股价回碰到250天均线，**全部卖掉**；
- 每笔投入不超过本金的10%。

内核一句话: **牛市抓中间一段，熊市避开**。参数本身不神圣——200/150/300天均线都可以换，但必须事先固定；系统的价值全在"照规矩办"，作者特意叮嘱"别找不做的理由。规矩就是规矩，按既定方针办"。代价同样明确: 它放弃了临界点体系更高的胜算，换来几乎零判断负担、每次执行都可核查。作者同时声明"您永远不知股价会跌多低，您也不知股价会升多高"——所以系统不设目标价、不猜顶底。

## A1 — 应用示例 (Application Example)

### 示例 1: 上穿买入全程推演

- **类型与来源**: 原书未提供案例（250天线系统为纯规则单元，无配套案例/反例候选）；以下为**合成演练**，按四条规则复算，数据为虚构。
- **问题/输入**: 虚构A股"辛通信": 250日均线=16.00元，某日放量自下而上上穿，收盘16.40元；可用本金100,000元。演练另给定: 该股其后最高涨至22.00元，约8个月后回落，回碰250日线时该均线已上移至19.70元（实际均线值以行情计算为准，此处为给定条件以保证可复算）。
- **方法论的使用**（逐条对应）:
  1. 进点: 股价上穿250日线（16.40>16.00）→ 按规则1在16.40元附近买入；
  2. 仓位: 每笔≤本金10%=10,000元；A股整手取整买600股（16.40×600=9,840元≤10,000元；整手为执行适配，原书按美股股数表述）；
  3. 止损: 16.40×(1−8%)≈15.09元（原书给5%–8%区间、未给选择规则，演练自选8%并全程固定）；
  4. 持有: 其后股价最高22.00元，始终收于250日线上方 → 按规则3坐等，不因浮盈提前止盈（"您不知股价会升多高"）；
  5. 卖出: 股价回落回碰250日线（19.70元）→ 全部卖出。
- **结论**: 盈亏=(19.70−16.40)×600=+1,980元，相对投入9,840元为+20.1%；持有期间浮盈一度达+34%而未动作，即"抓中间一段"的执行形态。
- **结果**: 合成演练输出，无实际市场结果；原书未提供该系统的回测数据。

### 示例 2: 买入即失败的两种离场（同一演练的失败分支）

- **类型与来源**: 同上，合成演练。
- **问题/输入**: 同上入场（16.40元买600股，止损15.09元，当时250日线16.00元）；买入后行情未站稳。
- **方法论的使用**:
  - 分支a（常规回落）: 股价回落先回碰250日线（≈16.00元）→ 按规则3全部卖出，亏(16.40−16.00)×600=240元（−2.4%）；此路径止损价15.09元未被触及——回碰线先发生，系统的常规小亏出口是"回碰离场"。
  - 分支b（跳空急跌）: 次日大幅低开直接跌破15.09元 → 按规则2止损离场；若以15.09元成交，亏600×1.31=786元（−8.0%）。A股涨跌停/一字板下实际成交价可能劣于止损价（滑移为执行适配，原书未处理跳空）。
- **结论**: 回碰线卖出是第一顺位出口，5%–8%止损保护的是跳空跌穿、无法在回碰价成交的场景。
- **结果**: 合成演练输出。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 新手问"有没有不用学K线图形、照做就行的简单买卖规则"；
2. 拿一只股票问"用250天线看，现在该买、该等还是该卖""跌破年线要不要清"；
3. 自述"管不住手/没时间盯盘/总是临场改主意"，要一套机械规则约束自己；
4. 问"均线系统怎么用""听说年线上方才持股，怎么操作"。

### 语言信号 (用户的话里出现这些就应激活)

- "250天线""250日均线""年线""200天线""300天线"
- "简单规则""极简系统""机械规则""照做就行""别让我判断""没时间盯盘"
- "上穿年线买""跌破年线卖""坐等""抓中间一段"
- 英文: 250-day moving average / annual line / simple mechanical trading system / rules-based

### 与相邻 skill 的区分（初稿，阶段 3 回填定稿）

- 与 `critical-point-buy-skill` 的区别: 本卡是**极简均线规则**，只有"价格与250日线的相对位置"一个维度，不做图形细读；对方是**图形态临界点的细读**（前峰前谷、支撑阻力、颈线、量价确认）。用户要"简单规则照做"用本卡，要"解读这个突破形态、找临界点定止损"用对方。两者对"何时买"的触发不同: 上穿年线 vs 临界点确认——两套触发并存时以用户事先选定的那套为准，不得混用。
- 与 `money-management-skill` 的区别: 本卡含"每笔≤本金10%"，但整体是**进出场规则系统**（何时买/何时卖/何时坐等）；对方是**仓位方法论**（分几份、胜率-仓位、1:3、分层加码），不给进出场触发。本卡的10%是系统内置上限，更细的注码问题转对方。
- 与 `motion-normality-skill` 的区别: 本卡单维度机械核对；对方是四维+量价的正常性判定，需要读图与量能数据。

## E — 可执行步骤 (Execution)

**必需输入**: ①当前股价；②250日均线值（或足够长度的日收盘序列——A股约250个交易日——供计算；分红除权建议用前复权口径，原书未规定，此为执行约定）；③本金。①②缺失时先询问或由序列计算，**不得猜值**。

**交付物与完成标准**: 输出四选一动作+所依据的规则条款+触发价——**买**（附止损价与按"≤本金10%"折算的股数）/**持有**（坐等）/**卖**（回碰线即全部卖出）/**不参与**。动作与条款一一对应才算完成；不输出目标价（原书明言"您永远不知股价会升多高，也不知会跌多低"）。

当 skill 被激活后，按以下步骤执行:

1. **核对价格与250日线的相对位置**
   - 完成标准: 记录三态之一——现价>均线 / 现价≤均线 / 恰在上穿；并记录均线值。

2. **按三态分流（判停分支）**
   - 现价在250日线下方且未上穿 → 输出"不参与"（规则1），流程终止；
   - 恰在上穿（本K线自下而上穿越）→ 进入步骤3买入流程；
   - 在250日线上方 → 已持仓则输出"持有（坐等）"；未持仓时规则只保证"可买"，是否新开仓结合本金安排输出"持有/观望"，流程终止。

3. **买入执行（触发=上穿时）**
   - 完成标准: 触发价（上穿日收盘附近）+止损价（入场价×(1−自选止损%)，5%–8%自选后全程固定）+仓位（≤本金10%，A股整手取整）三项同时给出。

4. **持有与卖出监控**
   - 完成标准: 持仓期间价格在250日线上方 → 不动作；价格回落触及250日线 → 输出"全部卖出"（规则3）。
   - 判停条件: 跳空跌穿止损价、或回碰点无法成交（如跌停封死）→ 按规则2止损离场，并注明实际成交滑移。

5. **参数变更纪律**
   - 完成标准: 若改用200/150/300天线，须在入场前一次性固定并记录；入场后不得中途换参数（"规矩就是规矩，按既定方针办"）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户想要"为什么这里能买"的形态解释与胜算评估 → `critical-point-buy-skill`（本卡是机械规则，不给图形理由；两套触发并存时以用户事先选定的那套为准，不得混用）。
- 震荡市: 价格围绕年线反复穿越时，本规则会反复进出、被来回洗——原书未给过滤条件；使用者应事先认识到这是系统的已知失效情景并自行定义停用判据（原书未定义系统失效判据，如实标注）。
- 问"这套系统历史年化多少、最大回撤多少" → 原书无回测数据，无法回答，不得编造。
- 问某股"运动是否正常、是洗盘还是出货" → `motion-normality-skill`（需要量价与四维图形信息，超出本卡单维度规则）。

### 作者在书中警告的失败模式

- "别找不做的理由。规矩就是规矩，按既定方针办"——给了规则不执行、临场找借口跳过或改规则，是本系统的头号失败模式（作者原文叮嘱）。
- "您永远不知股价会跌多低，您也不知股价会升多高。赚钱慢慢来，不要急！"——不设目标价、不猜顶底；坐等期间因浮盈焦虑提前下车，同样违反规则3。

### 作者的盲点 / 时代局限（阶段 0 批判）

- **参数无回测支撑**: 作者给出具体参数与止损区间但未提供统计验证（阶段0批判明确记录"250天线操作系统给出具体参数却无回测支撑"）；5%–8%区间取哪一档原书也未给选择规则，须自选后固定。
- **美股经验直接套A股的制度差异**: "有时可能股价几年都不回到250天均线之下"基于美股长牛；A股牛短熊长、涨跌停与T+1会改变回碰频率与成交可行性，"抓中间一段"的效果可能打折——此为适用性存疑点，非作者已论证的结论。
- 分红除权、停牌对均线的扰动原书未讨论；"每手"按美股股数表述，A股整手为执行适配。

### 容易混淆的邻近方法论

- **与作者自己的临界点体系存在张力**: 作者曾讥讽"如果炒股居然简单到'20天平均线穿越50天平均线是买入好点'的话，哪里还有人起早摸黑去上班"（机械绝招不存在），而250天线系统恰是机械规则。作者的调和是: 完整体系"对大多数读者要求太高"，故以可执行性换胜算。使用本卡须明白这是取舍，不是"均线金叉必涨"的技术信仰。
- 与"指标见光死"的警告同源: 作者对技术指标的总警告（公开指标会失效）同样适用于本卡——本卡的价值在纪律而非预测力。
