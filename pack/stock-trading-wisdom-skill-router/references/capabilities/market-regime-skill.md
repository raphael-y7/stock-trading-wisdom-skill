# 大市判定清单

## R — 原文 (Reading)

> "炒股的诀窍便是在牛市中全力投入，在牛市结束或接近结束的时候卖掉你的所有股票。"
>
> — 利物莫，转引自陈江挺，第二章第三节"我怎样看股票的大市"章首

> "炒股是概率的游戏，逆大潮流而动，你的获胜概率就被大打折扣了。……大市不好时，别买任何股票。"
>
> — 陈江挺，第二章第三节"我怎样看股票的大市"

## I — 方法论骨架 (Interpretation)

这是全书层级最高的判定：先回答"大盘现在什么方向、今天允不允许买"，再谈买哪只。核心做法是把股票指数当成一只股票来看——每天追踪指数，用技术分析判断它处在哪个运动阶段（蓄劲/爬坡/疲劳/下坡）、运动是否正常，作者认为这是判定大市最有效的工具。

在阶段判定之上叠加三类检查：

1. 总量背离：交易总量很大而指数不升、或高开低收，是危险信号。
2. 六点注意：政治经济大环境变动；本国经济大势、通胀、汇率、央行利率；龙头股是否率先疲软；垃圾股/三四线股是否突然活跃；每日涨跌家数分布（防综合指数被权重股糊弄）；类别股分化（大市不明显时按类别形态定个股）。
3. 情绪逆向：街头巷尾民众都在谈股市容易赚钱时，大市往往已到顶或接近到顶（入市资金已尽、推动力枯竭）；大众恐惧时该卖的已卖完，跌势差不多到头。

底部用两段式确认：大跌后某天放量狂升 1%~2% 只说明大户入场，还不是进场的最佳时机；等指数突破上一浪最高点、图上出现升势特点，才证实跌势基本结束。大市转向比个股慢（数天至数星期），感到危险时必须采取行动。输出是大市方向加入场许可，它是选股三步的第一道否决闸——大市不好时，别买任何股票。

## A1 — 应用示例 (Application Example)

### 示例 1: "街头巷尾都谈股票"=接近到顶的情绪逆向信号
- **类型与来源**: 作者经验规则（原书第二章第三节正文及章首题记两处，cases x48 素材）。
- **问题/输入**: 市场情绪位置——周围人谈论股票的热度与恐惧程度。
- **方法论的使用**: 正向读法：当街头巷尾的民众都在谈论股市如何容易赚钱时，人人都已将资金投入股市，继续升高的推动力枯竭，大市往往已到顶或接近到顶。反向读法：大众恐惧的时候，该卖的都已经卖了，股票的跌势也就差不多到头了。
- **结论**: 情绪狂热=顶部预警（停止新买入）；大众恐惧=底部临近（但须再过底部确认信号，不能就此进场）。
- **结果**: 原书未交代具体交易结果（信号规则）。

### 示例 2: 底部两段式——放量长阳不是最佳买点，突破前高才确认
- **类型与来源**: 原书规则表述（第二章第三节，作者经验）。
- **问题/输入**: 股市跌了很多、跌到大家都失去信心之后，什么时候能进场。
- **方法论的使用**: 第一信号=某天股市狂升 1%~2% 且交易量很大——这是跌到底的信号，大户开始入场；但"这还不是进场的最佳时机"，被下跌套牢的股民可能趁这个反弹卖股离场。确认信号=此后指数突破上一个波浪的最高点，图上出现升势特点，才证实跌势基本结束、是进场的时机。
- **结论**: 第一信号只观察不进场；突破上一浪高点后才可进场。
- **结果**: 原书未说明具体指数实例结果。

### 示例 3: 汇丰银行糊弄综合指数——涨跌家数的必要性
- **类型与来源**: 原书例题（worked_example），第二章第三节六点注意第⑤条，cases c25。
- **问题/输入**: 某天有 1/4 的股票跌、3/4 的股票升，但 1/4 的跌股中有一只在综合指数占大份额的股票（如香港的汇丰银行），使综合指数下跌。
- **方法论的使用**: 综合指数有时会被几只大权重股票糊弄，不完全反映大市的真实走向，须核对每日涨跌家数看真实分布。
- **结论**: 指数跌而多数股票升时，不能仅凭指数判定大市走坏。
- **结果**: 例题演算，未涉及实际交易。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 决定要不要入市、要不要继续持股之前，想知道"现在大盘行不行"。
2. 身边人人都在谈股票、媒体一片欢腾，怀疑是不是要见顶了。
3. 大跌之后想抄底，问"现在是底了吗、什么时候能进"。
4. 指数在涨但手里的股票不涨（或反之），怀疑指数失真。
5. 需要给选股/买入决策一个"今天允不允许买"的总开关。

### 语言信号 (用户的话里出现这些就应激活)

- "现在是牛市还是熊市？""大盘能不能入场/该不该清仓？"
- "是不是见顶了/见底了？""还能涨/还跌多久？"
- "全民都在炒股，正常吗？"
- "为什么指数涨我的票不涨？"
- "is it a bull or bear market" / "is the market topping" / "should I stay out of the market"

### 与相邻 skill 的区分 (初稿，阶段 3 回填定稿)

- 与 `motion-normality-skill` 的区别: 对方判定单只个股的走势正常性；本卡把指数当一只股票，判定整个市场的阶段与方向。工具同源（阶段+正常性+量价），检查对象不同。
- 与 `bubble-mania-skill` 的区别: 本卡处理日常牛熊判定与顶底预警；对方处理"疯"级极端泡沫的六特性识别与参与退出。常规牛市分析用本卡；确认进入狂热泡沫时两卡并用。
- 与 `return-allocation` 的区别: 本卡只输出方向判定与入场许可；仓位大小与资产配置决策归对方。

## E — 可执行步骤 (Execution)

**必需输入** (缺失先询问，不能静默猜值):
1. 代表性指数的走势图或阶段描述（A 股用沪深 300 等代表性指数；注意权重股失真）。
2. 每日交易总量与当日指数表现（升/平/高开低收）。
3. 龙头股近期表现（板块龙头是否疲软）。
4. 垃圾股/低价小盘股活跃度。
5. 每日涨跌家数（升家/跌家）。
6. 类别股形态（金融/电子/地产等哪些升、哪些跌）。
7. 周围谈论股票的情绪（狂热/中性/恐惧）。

**交付物与完成标准**: 输出 = 大市方向（牛/熊/震荡）+ 入场许可（可全力买入/停止新买入/观望/离场）+ 触发的危险信号清单（逐项列出）；完成标准 = 七项输入各有一行核对结论、结论可检查；不给综合评分（原书即定性清单，不补造权重）。

当 skill 被激活后, agent 应按以下步骤执行:

1. **阶段判定——把指数当一只股票**
   - 完成标准: 指数所处阶段（蓄劲/爬坡/疲劳/下坡）与运动正常/异常各给出一条结论（技术分析对指数最有效）。

2. **总量背离检查**
   - 完成标准: 明确回答有无背离——总量很大而指数不升、或高开低收=危险信号。

3. **六点注意逐项核对**
   - ①大的政治经济环境变动；②本国经济大势、通胀、汇率、央行利率动向；③龙头股是否率先疲软（到顶前兆）；④垃圾股/三四线股是否突然活跃（到顶前兆，游资涌向低价股）；⑤每日涨跌家数分布（防权重股糊弄综合指数）；⑥类别股分化（大市不明显时按类别形态定个股买卖）。
   - 完成标准: 六项各有一行核对结论。

4. **情绪逆向核对**
   - 完成标准: 情绪位置（狂热/中性/恐惧）及对应预警——街头巷尾都谈股易赚=顶或近顶；大众恐惧=跌近尾。
   - 判停条件 A: 若总量背离 + 龙头疲软 + 垃圾股活跃 + 全民狂热等多项顶部信号同时成立，跳到步骤 6 输出"顶部预警：停止一切新买入"——感到危险的时候必须采取行动，已有持仓收紧卖点规则执行。

5. **底部确认序列（仅当判定处于底部区域时执行）**
   - 第一信号: 大跌后放量狂升 1%~2%（大户入场迹象）——只观察，不进场。
   - 确认信号: 指数突破上一个波浪的最高点、图上出现升势特点——此时才可进场。
   - 完成标准: 两个信号各标注"已出现/未出现"；确认信号未出现前入场许可=观望。

6. **汇总输出**
   - 判停条件 B: 若大市判定为不好/转弱，输出"不买任何股票"（否决级），下游选股流程终止。
   - 完成标准: 大市方向 + 入场许可 + 危险信号清单三要素齐全，逐项可检查。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 想判定单只个股的走势正常性与危险信号——那是运动正常性卡的领地，本卡对象是整个市场。
- 面对六特性齐备的极端狂热泡沫、要决定参与或退出——用泡沫识别卡；本卡的情绪逆向只作日常顶底预警。
- 想知道该留多少仓位、怎么分仓——用资金管理/配置卡；本卡只给方向与许可，不给仓位。
- 没有指数走势与市场结构数据（总量、龙头、涨跌家数等）——不要凭感觉给大市方向，先补数据。

### 作者在书中警告的失败模式

- 新手用大量心思研究个股的基本面与技术面而忽视大市（"我自己以前也是一样"——总以为再坏的市场也有股票升）。
- 逆大潮流而动：获胜概率被大打折扣，久赌必输。
- 感到危险却不采取行动：大市转向需数天至数星期，犹豫即错过行动窗口。
- 在底部第一信号（放量狂升）就抢反弹：被套牢盘的解套卖压淹没。
- 只盯综合指数、不看涨跌家数：被权重股糊弄（汇丰例）。

### 作者的盲点 / 时代局限

- 全部信号为定性清单，无阈值与权重，结论依赖使用者综合判断。
- 情绪逆向无法定时点——顶部预警可能持续数月，据此提前清仓可能错过最后一段涨幅。
- 原书基于美股/港股经验（道指、恒生、汇丰例）；A 股应用需选代表性指数并注意权重失真（作者以汇丰例自己已提醒）、涨跌停与 T+1 改变转向节奏。
- "突破上一浪最高点"的浪划分有主观性；"牛市全力投入"与第九章"轻仓对大市风险"存在张力，阶段 3 需统一口径呈现。

### 容易混淆的邻近方法论

- "测势预测": 原书强调分析只是预测工具，"顺势而行"不等于预测本身；本卡输出之后仍需操作系统承接（买多少、怎么分仓、怎么止损）。
- 泡沫（疯）识别: 本卡是日常牛熊判定；"疯"识别针对一夜质变级别的极端泡沫，门槛远高于"到顶预警"。
- 个股技术分析: 同一套工具用于指数，但本卡结论只回答"允不允许买"，不回答"买哪只、何时买"。
