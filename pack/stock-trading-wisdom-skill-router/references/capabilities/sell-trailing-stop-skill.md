# 卖点与移动止损体系

## R — 原文 (Reading)

> "买入后，如果股票开始正常的升势，它应有一浪高过一浪的特点。你可以将止损点放在每个波浪的浪谷，随着波浪往上翻，你将卖点由→A→B→C→D→E往上移。这样就能保证你不会在升势时过早离场。"
>
> — 陈江挺《炒股的智慧》第四章第二节"小结·6.用移动止损点来卖股票"（图4-18）

> "华尔街将炒股的诀窍归纳成两句话：截短亏损，让利润奔跑！……一见股票情况不对，即刻止损，把它缩得越短越好！一旦有了利润，就必须让利润奔跑，从小利润跑成大利润。"
>
> — 陈江挺《炒股的智慧》第四章第二节小结末段（章首引文同源）

---

## I — 方法论骨架 (Interpretation)

1. 本卡只接手"何时卖"的后半题：入场时的初始止损设定（≤10%、硬顶20%、可取买入当日最低点）由临界点买点决策给出，本卡承接其后"有利润后怎样选择卖点获利"。
2. 持有总则只有一条：股票运动正常就不卖。持股通常数周至数月，无时间表；"不赚不卖"的心态被作者点名禁止。
3. 不猜最高点：一轮大走势头尾都难抓，能抓到中间约70%的涨幅已是好成绩——所以卖出永远由条件触发，本卡不产出价格目标。
4. 万能初筛问句："我愿此时买进这只股票吗？"答案是否定就考虑卖——但它只是初筛，真正的卖出动作靠下面六类触发。
5. 卖出六招：①注意危险信号（缓升中突然大起大落，"该卖了"的直觉即经验）；②保本第一（浮盈后把止损上移到进价上方约10%，绝不让利润变亏损）；③亏小钱（入场初期止损越小越好）；④遇有暴利拿了再说（两周翻倍级暴升＋量猛增＋无特别好消息，第一天转头即卖）；⑤量增价滞（升了一段后放巨量滞涨＝有人出货）；⑥移动止损卖出。
6. 移动止损是机械主体：止损＝最近一个已完成上升浪的浪谷，每翻起一浪就把卖点沿A→B→C→D→E逐级上移，只上移不下移；跌穿当前一级全部离场。
7. 形态卖点（图4-12~4-14）：破双头颈线、破箱体支撑线、跌破升势均线，都是"投资大众对股价重新评估"的临界点；进阶做法（图4-15）可把卖点提前到第二波峰附近，股价再度向上穿越阻力线就重新买入。
8. 底层是一句话：亏损端截短、盈利端放跑；利润也是真钱（别把5000元只当纸面利润），到价必须当机立断。

## A1 — 应用示例 (Application Example)

### 示例 1: 移动止损 A→B→C→D→E 的卖出执行
- **类型与来源**: 原书例题/图示（第四章第二节小结·6，图4-18；"10000元的赚钱机会只赚到2000元"为同节原话）。数字演算部分为阶段1.5纸面演练（verify_units.md U04 V2 walkthrough），非作者实盘记录。
- **问题/输入**: 以15.5元入场（初始止损14.5元，由买点规则给出）；随后股价 15.5→18（浪谷17）→21（浪谷19.8）→24，之后回落。
- **方法论的使用**: 每完成一个上升浪就把止损上移到最近浪谷：14.5→17→19.8；全程止损高于进价15.5（招2保本自动满足）；不设目标价、不猜最高点。
- **结论**: 跌破19.8元 → 触发移动止损，全部卖出，落袋约4.3元/股。
- **结果**: 原书对该机制的承诺："你抓不到这个升势的头尾，但你能抓住中间的大部分"；不做移动止损的代价被原书量化为"一个10000元的赚钱机会只赚到2000元"。演练输出如上（纸面演算，未实测）。

### 示例 2: 反例——到价迟疑的下场（1994-11-02 迟疑日记）
- **类型与来源**: 作者亲历（第五章第一节"该卖股票的时候，要当机立断，千万别迟疑！"）。
- **问题/输入**: 1994-11-02 日记原文：xirc，2000股，进价17.25元，最高升至23.50元，作者已把卖点定在21.50元。
- **方法论的使用（应做未做）**: 股价从23.50回落触及21.50卖点时，应"不要幻想，不要期待，不要讲理由，即刻卖掉"；实际当日迟疑未执行。
- **结论**: 股票跌到16.25元，原本8500美元的利润倒亏2000美元（作者痛呼"蠢啊蠢！！！痛啊痛！！！"）。
- **结果**: 如上（作者日记实录）。该反例同时揭示迟疑机制：下跌途中总有反弹给一线希望，几个来回小亏变大亏——这正是已学会止损的股友还会亏大钱的原因，所以到价执行必须无条件。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 手里有一只浮盈或浮亏中的持仓，问"现在该不该卖、卖在哪、卖多少"——已过了买入决策阶段。
2. 股票升了一段开始回调，纠结"这是正常回调还是到顶了，要不要先落袋为安"。
3. 利润快被抹平甚至转亏，问"止损怎么设/怎么上移、怎么保住战果、别让利润变亏损"。
4. 想给趋势股定一条"跌破就走"的机械线（不能整天盯盘），问移动止损/跟踪止损怎么画。
5. 遇到短期暴涨或放巨量滞涨，问"是不是该兑现了/是不是有人在出货"。

### 语言信号 (用户的话里出现这些就应激活)

- "什么时候卖""卖点怎么定""止盈""落袋为安""保住利润/战果"
- "移动止损""跟踪止损""trailing stop""跌破某价位就走""沿浪谷/低点抬高止损"
- "涨这么多了要不要卖""放量不涨是不是该跑了""别让利润变亏损""cut loss short, let profit run"

### 与相邻 skill 的区分

- 与 `motion-normality-skill`（运动正常性判定）的区别: 对方诊断"走势是否正常/该不该继续持有"，输出正常或异常的判断；本卡执行"走的时候卖在哪一档、止损怎么随趋势上移"。判定链上对方的"异常"结论会进入本卡招1的触发条件。
- 与 `critical-point-buy-skill`（临界点买点决策）的区别: 对方管入场触发与初始止损的设定（入场前），本卡管入场后的卖点与止损上移（入场后）。招3"亏小钱"的初始止损口径与对方同源（≤10%硬顶20%、当天最低点法），两卡口径一致、不重复展开。
- 与 `psych-discipline`（心理纪律自检）的区别: 本卡给操作规则（触发→动作→价位），对方给"知易行难"的自检清单（到价当机立断、忘掉进价、纪律训练）。用户问"明知该卖却下不了手"时优先对方。

## E — 可执行步骤 (Execution)

**必需输入**: ①持仓信息：买入价/成本价、现价、持仓量、买入当日最低价（初始止损用）；②走势结构：入场后的浪谷序列（最近几个上升浪的谷底价）或支撑线/均线位置，近期成交量与均量的对比，有无特别好消息（招4用）；③上游结论：股票运动是否正常（可引用运动正常性判定的输出）。缺失买入价、现价或浪谷/支撑结构时先询问，不得静默猜值；用户给不出浪谷序列时退化为"进价上方保本线＋最近明显低点"，并声明精度下降。

**交付物与完成标准**: 卖出决策 = 卖出触发依据（六招或三图之一）＋卖出价或触发价＋卖出比例与剩余仓位＋重入条件；每项可回溯到原书规则。无触发时输出"持有＋当前止损位＋下次复核条件"。A股涨跌停、跳空为执行适配层（原书未处理，见B段），不改变决策本身。

当 skill 被激活后, agent 应按以下步骤执行:

1. **建立持仓快照并做初筛**
   - 记录买入价、现价、浮盈%、当前止损位；问总检验问题"我愿以现价买进这只股票吗？"（仅初筛，不直接驱动卖出）。
   - 完成标准: 一行快照齐备（成本/现价/止损位/浮盈%）。

2. **按六招顺序核对触发（先到先执行；危险信号类优先）**
   - 招1 危险信号：缓升途中突然暴升放量又迅速回落（对齐 50→55→62→58→64→61 样板）→ 全部脱手。完成标准: 给出"是/否＋量价证据"。
   - 判停条件: 招1触发 → 跳到步骤4执行离场（几天后恢复正常可重入，重入条件写入输出）。
   - 招2 保本第一：现价>买入价且止损低于买入价 → 止损上移到进价上方约10%（10元进升到12元→卖点定11元；禁止贴现价定11.90，须留约10%喘息空间）。
   - 招3 亏小钱：尚无利润时止损≤10%、硬顶20%、越小越好；可定在买入当日最低点；低价股按绝对值放宽（5元股给0.75元空间→4.25元；50元股给3元→47元）。
   - 招4 暴利拿了再说：两周内翻倍级暴升（20→40）＋最后两天交易量猛增＋无特别好消息 → 第一天转头（收盘<开盘）即卖。判停条件: 触发 → 跳步骤4。
   - 招5 量增价滞：升了一段后交易量猛增而股价不创新高 → 短期到顶信号，卖出。判停条件: 触发 → 跳步骤4。
   - 招6 移动止损：止损＝最近一个已完成上升浪的浪谷；每创新高、浪谷上移，卖点沿A→B→C→D→E同步上移，只上移不下移。判停条件: 股价跌穿当前浪谷价位线 → 全部卖出，流程终止。
   - 完成标准: 六招各给出"触发/未触发＋依据"，或已在某一招判停。

3. **无触发 → 维持持有**
   - 输出"持有＋当前止损位＋下次复核条件"；不得以"股价很高了"当卖出理由（原书双向禁令）。
   - 完成标准: 结论唯一且含当前止损位。

4. **执行与重入（到达触发点时）**
   - 形态卖点可选进阶：破双头颈线（图4-12）/破箱体支撑线（图4-13）/跌破升势均线（图4-14）；进阶做法（图4-15）把卖点提前到第二波峰附近，若股价再度向上穿越阻力线则重新买入——原书明示这是"思考方式"，可在实践中修正。
   - 到价执行：定好出场价，跌到即卖，不幻想、不期待、不讲理由。
   - 完成标准: 卖出决策四字段（触发依据/触发价/仓位动作/重入条件）齐备。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户还在决定"要不要买、买多少"——那是临界点买点卡与资金管理卡的领地（本卡只消费它们的输出）。
- 问的是资产配置战略（拿多少钱入市、股债/基金怎么配、合理回报）——属战略层课题。
- 要求预测最高价或给出目标价——原书明言"不要试图寻找股票的最高点，你永远不知股票会升多高"，本卡不产出价格目标。
- 分钟级短炒风格——原书第四章第三节明说短炒"到获利点就平仓，别让'让利润奔跑'这句话影响操作"；本卡的移动止损针对日线级波段持有。
- 没有任何价格/成交量数据的纯基本面讨论。

### 作者在书中警告的失败模式

- 到价迟疑：1994-11-02日记 17.25→23.50→21.50未卖→16.25，8500美元利润倒亏2000（作者亲历）。
- 止损下移：作者摸索阶段自述把止损从27美元下移到26/25，"我知道这样做不对，但我忍不住"——止损只上移不下移必须当铁律而非临场判断。
- 不赚不卖/卖盈留亏：新手把赚钱的先卖、套牢的留着；"不赚不卖"的心态＝失败命运差不多注定。
- 过早离场抓小钱：利物莫应赚2万只赚2千；"一个10000元的赚钱机会只赚到2000元"。
- 别让利润变亏损：10元进升到12元，止损必须定在10元之上（10.50~11），跌回9元才割肉＝愚蠢操作。
- 频繁进出："频繁进出场的结果就是把利润都捐献给政府和证券商了"。

### 作者的盲点 / 时代局限

- 原书基于美股未处理跳空：A股跌停开盘或跳空低开时，实际成交价可能远低于止损设定价，止损≠锁定损失上限。
- 六招可能同时触发且原书未给优先级（如"暴利拿了" vs "安坐不动"）；"危险信号优先、先到先执行"是本卡的下游约定，非原书规则。
- "抓中间70%""很少有股票沿最小阻力线运行1年以上"为作者个人经验自述，无样本统计；"直觉是经验"只对交过学费者成立，新手仍以规则为主。
- 招4/招5的"大户找傻瓜"机制解释基于1990s庄股叙事；现代A股（量化、信息披露监管）下形态可能变形，但量价背离本身仍可观察。
- 危险信号≠必跌：作者自问自答"是否一定下跌？否！"——离场逻辑是胜算回落到50%，不是预测顶部。

### 容易混淆的邻近方法论

- `motion-normality-skill`：判断"正常/异常"（持有还是离场），本卡执行"离场时的价位与止损管理"；两者共享危险信号样板但问题不同。
- `critical-point-buy-skill`：初始止损设定是两卡交界（同口径：≤10%硬顶20%、当天最低点法）；对方管入场前，本卡管入场后。
- `psych-discipline`：到价当机立断、忘掉进价的执行心理在对方卡；本卡只管规则本体。
