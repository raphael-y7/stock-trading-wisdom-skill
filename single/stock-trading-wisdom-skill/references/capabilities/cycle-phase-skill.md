# 周期四阶段定位

## R — 原文 (Reading)

> "可以将股票运动大约分成四个时期，分别为蓄劲期、爬坡期、疲劳期和下坡期。蓄劲期:买卖双方的力量基本平衡。爬坡期:买压胜过卖压。疲劳期:买压和卖压又基本持平。下坡期:卖压强过买压。"
>
> — 陈江挺，第二章第二节"股票的周期性运动"

> "在蓄劲后期，爬坡初期，如果是开始一个真正的爬坡期，应有交易量增加的现象，股价一举突破阻力线。……在这段时间，投资者必须安坐如山，不要为股价的短线升跌吓出场，但要打起十二分精神注意危险信号。经过疲劳期，股价跌穿平均线及支撑线，便是离场的时候了。"
>
> — 陈江挺，第二章第二节"股票的周期性运动"（原文中间省略"一波高过一波/200天线上方"两句）

---

## I — 方法论骨架 (Interpretation)

作者认为道氏、波浪等理论"读起来又长又乏味……很难在实践中应用"，其实它们讲的无非是经济周期。于是把周期直接搬到个股上：一只股票的长期运动大约分四个时期——蓄劲期（买卖力量基本平衡，图上横盘）、爬坡期（买压胜过卖压，升势）、疲劳期（再度基本持平，筑顶）、下坡期（卖压强过买压，跌势）。四期在均线上表现为一条大弧，并吻合经济周期的恢复→复苏→过热→回落。

判定的锚点有三：价格形态（横盘/一波高过一波/一波低过一波）、均线位置（爬坡期整段波动应在 200 天线上方）、量能（真升势起点必须有量）。阶段定位的价值在于操作许可：蓄劲期观望待突破；蓄劲后期/爬坡初期"交易量增加+一举突破阻力线"两条件齐备=真升势起点（可入场）；爬坡期安坐如山、只盯危险信号；疲劳期警惕；跌穿均线及支撑线=离场；下坡期不碰。

两条底线性认知：股市操纵可能改变每天的或短期的波动，但不可能改变大势；小公司同样走四阶段，只是起伏更剧烈。本卡输出是"背景许可"——先定位阶段，再用买点卡定入场、运动正常性卡做持有期健康检查。

- **方法论的使用**: 按图逐段读量价——蓄劲期：柱子短小、价格横盘（买卖力量基本平衡）；爬坡初期：量明显放大（图上标注文字"爬坡初期，交易量增加"）、股价突破阻力线进入爬坡段（买压胜过卖压，均线上方一波高过一波）；疲劳期：高位横盘、买卖力再度持平（警惕；图示量柱高矮交替延续）；下坡期：卖压占优、跌破均线及支撑线（离场；末段量柱转小）。
- **结论**: 四阶段各有可观察的量价指纹；真升势起点="交易量增加+股价一举突破阻力线"两条件齐备，缺一即假启动。
- **结果**: 教学图例，不涉及实际交易。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿着一只长期横盘/创新高/破位的股票，问"现在处于什么阶段，能买吗、该拿住吗、该跑吗"。
2. 想在月线/周线级别定位长期趋势（"这票横了一年了算什么"）。
3. 问"放量突破阻力线是真启动还是假突破"（蓄劲→爬坡的阶段转换确认）。
4. 需要给买入/持有决策一个阶段级背景许可（先定阶段再谈买卖点）。

### 语言信号 (用户的话里出现这些就应激活)

- "这股票现在什么阶段""是蓄势还是筑顶""是不是走下坡了"
- "横盘很久了算不算蓄劲""什么时候能起来"
- "放量突破阻力线，是真升势开始了吗"
- "长期趋势怎么定位""月线/周线上看怎么样"
- "what cycle phase / stage is this stock in"

### 与相邻 skill 的区分 (初稿，阶段 3 回填定稿)

- 与 `motion-normality-skill` 的区别: 对方是日线级健康检查（正常/异常→持有/离场）；本卡是月线级阶段定位（四选一→操作许可）。本卡输出直接作为对方与买点卡的背景许可条件。
- 与 `market-regime-skill` 的区别: 个股生命周期 vs 全市场方向。把指数当股票看时，大市卡复用本卡的四阶段逻辑，但检查对象与结论层级不同。

## E — 可执行步骤 (Execution)

**必需输入** (缺失先询问，不能静默猜值):
1. 足够长的价格序列：最好含月线/周线视角，覆盖至少一轮横盘-升-顶（或至今仍横盘）的结构；只有几天的数据无法定位阶段。
2. 均线数据：长期均线（作者日常用 200 天线）数值与股价相对位置。
3. 量能序列：关键节点（横盘期/疑似突破期）成交量相对平时水平。
4. 关键价位：横盘区上沿（阻力线）与下沿（支撑线）。

**交付物与完成标准**: 输出 = ①阶段判定（四选一+依据）②真升势起点确认（如疑似蓄劲→爬坡转换：两条件各标满足与否）③操作许可表（当前阶段动作+后续触发条件）④离场触发（跌穿均线及支撑线）。完成标准 = 每项可检查；四阶段为定性划分（原书明言"大约分成"），不给量化边界，不补造原书没有的动作。

当 skill 被激活后, agent 应按以下步骤执行:

1. **阶段判定**
   - 蓄劲期=区间横盘、买卖力量基本平衡；爬坡期=一波高过一波、站上 200 天线；疲劳期=高位滞涨、买卖力再度持平；下坡期=一波低过一波、均线下方。
   - 完成标准: 四选一结论+价格形态/均线位置两条依据。

2. **真升势起点确认** (仅当疑似蓄劲→爬坡转换)
   - 两条件: 交易量增加 + 股价一举突破阻力线；缺一即视为假启动（只观察不入场）。
   - 完成标准: 两条件各标"已满足/未满足"。

3. **操作许可输出** (查表)
   - 蓄劲期: 观望、待突破（原书另提"低位吸纳"但未给任何具体条件——如实标注，默认按观望/待突破处理）。
   - 爬坡期: 持有者安坐如山、不为短线升跌吓出场、只盯危险信号；空仓者的入场触发转临界点买点卡（买点与止损成对出现）。
   - 疲劳期: 警惕（原书只给"警惕"、未给"减仓"等具体动作——如实标注，不擅自补充）。
   - 离场触发: 经疲劳期后股价跌穿平均线及支撑线（两线同时失效）→ 离场。
   - 下坡期: 不碰。
   - 完成标准: 许可表每格有结论且与原文口径一致。

4. **判停与转接**
   - 若判定下坡期 → 输出"不碰"；除非跌势末端再度向上突破（图 2-13"重新买入"点）→ 回到步骤 2。
   - 若爬坡期确认 → 转运动正常性卡做持有期日常健康检查（一浪高过一浪、升时放量回调缩量、均线之上）。
   - 完成标准: 输出注明下一步转接哪张卡。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 短线分钟级图表不适用——四阶段是月线级长期定位；日内短炒是另一套体系（10–30 分钟 K 线+固定止盈止损）。
- 单日/单周的放量异动与破位判断——用运动正常性卡/危险信号机制（日线级健康检查），本卡只做阶段级定位。
- 全市场方向判定——把指数当股票看是大市卡的做法；本卡对象是个股生命周期。
- 只有几天 K 线、用户拒绝提供长期数据——无法定位，先询问，不猜。

### 作者在书中警告的失败模式

- 阶段错配: 下坡期抢反弹、爬坡期被洗出——两头挨打。爬坡期纪律="安坐如山，不要为股价的短线升跌吓出场，但要打起十二分精神注意危险信号"。
- 洗盘被吓出 / 破位不走: 前者违反"安坐如山"，后者违反"跌穿平均线及支撑线，便是离场的时候"。
- 操纵干扰: 股市操纵可能改变每天的或短期的波动，但不可能改变大势——短期突破信号可能被操纵，须量能确认（假突破的识别归操纵痕迹卡）。

### 作者的盲点 / 时代局限

- 四阶段为定性划分、无量化边界（原书明言"大约分成"）；趋势线/支撑线/浪的画法原书未给统一定义，判定含主观成分。
- A 股涨跌停与 T+1 改变突破与离场的微观结构；"操纵不可能改变大势"是长期判断，不豁免短期信号失真。
- 小公司四阶段起伏更剧烈（作者语），阶段切换更快，判定容错更低。

### 容易混淆的邻近方法论

- motion-normality-skill: 对方日线级健康检查，本卡月线级阶段定位；本卡输出作为对方与买点卡的背景许可。
- market-regime-skill: 个股生命周期 vs 全市场方向；大市卡复用四阶段逻辑但对象与结论层级不同。
- 道氏理论/波浪理论: 作者明确认为"很难在实践中应用"而以四阶段替代——不把数浪、线段划分混入本卡。
