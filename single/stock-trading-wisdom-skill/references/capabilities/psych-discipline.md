# 心理纪律执行清单

## R — 原文 (Reading)

> "我不知该怎样强调这两个字的重要性，我也不知还能怎么解释这两个字，这是炒股行的最高行为准则。你如果觉得自己实在没法以比进价更低的价钱卖出手中的股票，那就赶快退出这行吧！你在这行没有任何生存的机会。"
>
> — 陈江挺《炒股的智慧》第五章第一节"华尔街的家训·止损，止损，止损！"

---

## I — 方法论骨架 (Interpretation)

1. 本卡不提供任何新规则，它管的是"知易行难"：规则都在买点、卖点、资金管理各卡里，本卡在**下单前**和**持仓中**两个时刻逐条核对"你有没有照规则做"，并给违规项对应的原书纠正规则。
2. 为什么需要这张卡：人性中根深蒂固的恐惧、贪婪、希望让"人们常常做不到自己知道该做的事情"；作者判断，因这三个心理因素而犯错的股民达99%以上——所以先查违规，再谈分析。
3. 三障碍的机制：恐惧让人该进反出、一有风吹草动就清仓（应赚5万只得5千）；贪婪让人重注、情绪性加码、"这注搏大的"；希望让人拒绝止损、每天只搜集有利信息、把不正常的走势"合理化"。
4. 交易前自检的核心是"内心声音四问"：升势吗？有新产品吗？大市牛熊？量价互动正常吗？——四问的目的是甄别这个"买"的冲动源自客观判断还是自以为是。
5. 持仓中的裁决器是重置检验：股票开始亏钱时问"原先买入的理由还对吗？如果我今天空仓、手上有余钱，还会按现价买它吗？"——任一否定即卖。
6. 13条华尔街家训（止损/分散/别买太多/有疑问离场/忘掉进价/别频繁交易/别摊平/别让利润变亏损/别跟朋友/当机立断/定计划照办/别爱上股票/市场从来不会错）是本轮自检的逐条清单。
7. 到价执行是最高优先级：出场价到了就"不要幻想，不要期待，不要讲理由，即刻卖掉"；发现"到价未执行"类违规时，纠正动作优先于继续自检。
8. 复盘归因：每次犯错问"违反了什么规则"，不找替罪羊（大户操纵、假新闻在量价上都有迹可循）；自己，也只有自己，对结果负全部责任。训练目标是"按规则行动愉快、不按规则痛苦"，把规则练成直觉（有招到无招）。

## A1 — 应用示例 (Application Example)

### 示例 1: 用清单核对一次到价违规（1994-11-02 迟疑日记）
- **类型与来源**: 作者亲历（第五章第一节"该卖股票的时候，要当机立断，千万别迟疑！"所引1994年11月2日炒股日记；数字经阶段1.5案例验证 c57 逐字核对）。
- **问题/输入**: 持仓 xirc 2000股，进价17.25美元，最高升至23.50美元，作者此前已把卖点定在21.50美元；股价从23.50回落。
- **方法论的使用（按清单逐项核对违规）**:
  1. 家训10（到价当机立断）——跌到21.50卖点时应"不要幻想，不要期待，不要讲理由，即刻卖掉"，实际"不知什么原因使我迟疑"，未执行 → 违规；
  2. 家训8（别让利润变亏损）——8500美元浮盈未把止损/卖点固化上移保护 → 违规；
  3. 希望障碍——下跌途中"总会不时给你来个小反弹，给你一线希望"，每个反弹都重置希望、拖延执行 → 违规；
  4. 重置检验——若当时自问"空仓手上有钱，还会按21.50买吗"，答案显然是否，即应卖出；
  5. 归因——违反的是家训10+家训8，纠正规则即原书口径"定好了出场价……即刻卖掉再说"，且止损概念要覆盖利润（"别把5000元仅当成纸面利润"）。
- **结论**: 清单输出唯一动作＝21.50全部卖出落袋；违规归因＝希望障碍+到价不执行。
- **结果**: 实际跌到16.25美元，原本8500美元的利润倒亏2000美元（作者日记实录，痛呼"蠢啊蠢！！！痛啊痛！！！"）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 下单前想自查"这单该不该下"：买入理由站不站得住、有没有书面计划、是不是冲动。
2. 持仓中发现自己"明知道该卖/该止损却下不了手"，套牢后开始自我怀疑。
3. 回顾交易记录发现固定坏习惯：赚点就跑、频繁交易、亏损加码摊平、情绪性重仓。
4. 亏损或违规后想复盘"我到底错在哪、违反了哪条规则"，而非仅纠结盈亏数字。
5. 发现已"爱上一只股票"（说得出公司愿景、说不出止损价），想被拉回纪律。

### 语言信号 (用户的话里出现这些就应激活)

- "管不住手""又追高/又冲动了""止损下不了手""明知道该卖却没卖"
- "忍不住频繁交易""赚点就想跑""被套了不想割""是不是我心态不行"
- "帮我复盘一下错在哪""违反了什么纪律""自查一下交易纪律""trading discipline / self-check / why can't I follow my own rules"

### 与相邻 skill 的区分

- 与 `sell-trailing-stop-skill`（卖点与移动止损体系）的区别: 对方给"该在哪卖、止损怎么上移"的**操作规则**；本卡查"**你有没有照规则做**"并给违规纠正。用户问的是点位时用对方，问"为什么没做到/又没执行"时用本卡。
- 与 `money-management-skill`（资金管理与仓位规则）的区别: 对方给"下多大注、怎么分仓"的规则本体；本卡核对仓位规则是否被执行（超份数、情绪加码、摊平），规则细节引用对方不展开。
- 与 `stage-selftest`（学股阶段自测与排障）的区别: 对方定位"我在学股哪个阶段、该练什么"（学习路径），本卡查"当下这笔交易的执行纪律"（即时自检）。复盘发现"不是忘了规则而是阶段不到"时转对方。
- 本卡不用于选股与图形分析：股票好不好、图形破没破，属于选股卡与运动正常性卡的领地。

## E — 可执行步骤 (Execution)

**必需输入**: ①场景声明：交易前（拟交易）或持有中（已有持仓），二选一；②交易前：标的、拟买入价、计划仓位、买入理由、有无书面计划（风险/回报/应变）；③持有中：持仓明细（成本价、现价、止损位/卖点、占总资金比）、近期交易频率、持仓期间有无加码/摊平/上移止损、是否只接收利好信息；④情绪自评（失眠？到价时心跳？）。缺失成本价、止损位或买入理由时先询问，不得静默猜值；用户拒绝提供的项目标注"无法核对"，不得跳过假装已查。

**交付物与完成标准**: 自检报告四件套——①逐项核对表（每条家训/障碍：符合/违规/无法判定＋行为证据）；②违规项汇总（每项＝违规名称＋证据＋原书对应纠正规则的原口径）；③立即执行动作（存在到价未执行类违规时必填）；④复盘归因（违反了哪条规则，供下次不犯同样错误）。无违规时输出"通过＋下次重点盯防2-3条"。所有纠正规则必须出自原书（家训/买点/卖点/资金管理各卡），不得补造原书没有的规则。

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认场景并建立快照**
   - 记录场景（交易前/持有中）与上述必需字段。
   - 完成标准: 场景唯一，快照字段齐备或已标注"无法核对"。

2. **第一轮：交易前自检（仅交易前场景）**
   - 内心声音四问: 这只股票处在升势吗？公司有新产品/经营亮点吗？大市是牛市还是熊市？价格与交易量的互动正常吗？——甄别"买"的冲动源自客观判断还是自以为是。
   - 资格检查: 有书面计划吗（本笔风险/回报/未按预想运行时的应变，家训11模板）；买入理由是否属于禁令类——"股价已跌很低了""好消息/专家推荐""朋友在买"。
   - 判停条件: 买入理由属禁令类，或无止损点 → 不下单，输出"缺哪条补哪条"，流程终止。
   - 完成标准: 四问各有一句回答＋资格检查通过/拦下。

3. **第二轮：持有中自检（13条家训＋三障碍逐项核对）**
   - 家训1 止损最高准则: 有止损位吗？跌破了执行了吗？
   - 家训2 分散风险/家训3 别买太多: 单笔超份数上限了吗？持股超出自己注意力极限了吗？（只查做没做，份数与只数口径引用资金管理卡）
   - 家训4 有疑问的时候离场: 对这只股票的走势还有感觉吗？
   - 家训5 忘掉进价: 当前的卖出/持有理由与成本价有关吗？
   - 家训6 别频繁交易: 是否每天不交易就难受？（"每天都有70％胜算的交易机会是骗人的"）
   - 家训7 不要向下摊平: 亏损中加码了吗？（纸面无利润不加码；升势回调加码是三五年级别炒手的例外）
   - 家训8 别让利润变亏损: 浮盈后止损上移到进价上方了吗（留约10%喘息空间）？
   - 家训9 别跟朋友走: 买入/卖出依据是市场还是他人？家训10 该卖就当机立断: 到价执行了吗？家训11 按既定方针办: 偏离书面计划了吗？家训12 别爱上任何股票: 研究投入是否已异化为感情绑定？家训13 市场从来不会错: 是否在用"市场错了"解释自己的亏损？
   - 三障碍症状: 恐惧（该进反出、一有风吹草动就清仓、随大众在底部割肉）；贪婪（情绪性加码、"这注搏大的"、资金不闲着勉强入市）；希望（拒绝止损、只搜集有利信息、把不正常运动合理化）。
   - 重置检验裁决: 持仓开始亏钱时问"原先买入理由还对吗？空仓手上有钱还会按现价买吗？"——任一否定即卖。
   - 判停条件: 存在"到价（止损/卖点）未执行"类违规 → 跳到步骤4，先输出立即执行动作。
   - 完成标准: 每条给出符合/违规/无法判定＋一句行为证据。

4. **归因复盘与输出**
   - 每项违规记录"违反了哪条规则"；不找替罪羊（大户操纵、假新闻、假账在量价上都有迹可循）；告诫自己下次不犯同样的错误——"自己，也只有自己，才能对结果负全部责任"。
   - 完成标准: 四件套齐备，纠正规则均可回溯原书章节。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问的是买卖点位、止损价位本身——那是卖点/买点卡的输出，本卡只核对执行，不产生价位。
- 问的是"该下多大注、怎么分仓"的规则计算——属资金管理卡；本卡只查规则是否被遵守。
- 选股（买什么股票）与图形分析（走势正常与否）——与执行纪律无关。
- 想要心理疏导安慰——本卡是行为核对清单，产出违规项与纠正规则，不提供情绪安抚。
- 评估学习进度与阶段——那是学股阶段自测卡的任务。

### 作者在书中警告的失败模式

- 火鸡式迟疑：跌破止损后"再等等反弹"逐级谈判，止损价18→16→10一路下移，最后赌气死扛（第一章第三节）。
- 赚小亏大的结构：夏皮诺实验——有利润立刻落袋、有亏损拒绝认赔，把公平游戏玩成必输结构（第一章第三节）。
- 情绪性加码：300股浮盈1500元后加到3000股，跌1元即由+1500变−1800（第六章贪婪节算例）。
- 爱上股票：修旧车效应——研究越深越有感情，"股票升应该的、跌是暂时的"，计划与止损统统让位（第五章家训12）。
- 跟风跟单：三个盲人走路；跟单者失去卖点信息、亏损有替罪羊（第五章家训9）。
- 频繁交易：作者自述"每天不买或卖上一次就觉得自己没完成当天的工作"，为此付出巨额学费（第五章家训6）。

### 作者的盲点 / 时代局限

- "从有招到无招要5-6年"与"80%股民无法毕业"均为作者个人观察，属幸存者样本；作者自己引用的"减肥成功率2%"恰是"知道做不到"之普遍性的反证，但反过来说明本卡也不能承诺"照做就能改"。
- "因三障碍犯错者达99%以上"无统计口径，是经验判断。
- 家训之间存在张力（家训10当机立断 vs 家训6别频繁交易；家训1止损 vs 洗盘误伤）——原书靠临界点规则统一定位（在临界点内到价必断、临界点外不动作）。"先判位置再查执行"的核对顺序是本卡的下游约定，非原书逐字规则。
- "直觉是长久实践产生的专业感觉"只对交过学费者成立；新手阶段仍以规则核对为主，不迷信直觉。

### 容易混淆的邻近方法论

- 卖点/买点/资金管理各卡: 规则本体在对方，本卡是执行检查层，两者是"规则-审计"关系而非重复。
- 学股阶段自测: 复盘发现违规是系统性的（不是疏忽而是阶段能力不到）时，应转阶段自测。
- 大师清单（巴鲁克十条、施瓦格15条）: 与家训高度重合，只作交叉佐证，不单独成方法。
