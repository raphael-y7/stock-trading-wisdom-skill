# 合理回报与战略定位

## R — 原文 (Reading)

> "很明显，回报一定围绕着指数转；指数可以认为是充分分散个股风险，100％资金入市后股票的平均回报。……我们用分仓应对个股分险，用轻仓应对大市风险。"
>
> — 陈江挺《炒股的智慧》第九章第二节"什么是股市可以期待的合理回报"（"个股分险"为原文如此）

---

## I — 方法论骨架 (Interpretation)

这张卡回答"我在股市到底该盼多少回报、拿什么姿态进场"。作者把炒股当作一场打不完的战役：既然只要败一次就可能前功尽弃，战略起点就不该是"一把翻倍"，而是"不怎么亏钱地让资本不断增值"。

执行顺序三步：

1. **先分流战略目标**。股龄不到5年一律先归学习期，目标是"用最小的代价了解股市"；过了这一步按资金性质归入三型——想赌一把（必须余钱，亏光不伤家）、走专业道路（需全面训练或可重复的实盘记录）、稳妥投资（绝大多数：有老有小、亏不起）。
2. **用回报预期校准配置**。股市风险分两类：个股风险（不知哪只股票大跌）用分仓化解；大市风险（不知大盘何时大跌）用轻仓化解。充分分散之后，回报必然围绕指数打转——美股约10%就是"合理回报"的锚；想超过指数，就得有识别并跟进升势板块、避开跌势板块的能力，绝大多数人（含80%的专业管理人）做不到。想翻倍？大约只能集中赌一只，那是赌，不是投资。
3. **以"善战者无赫赫之功"定基调**。结硬寨（先不受损失）、打呆战（有多少实力打多大的仗），靠胜率略高于50%的反复小胜加复利滚成大胜——连骗局都只敢吹年12%，巴菲特年化21.5%已是全球第一。

缺口如实标注：本章只给原则与参照口径（单票≤5%即至少20只=充分分散；满足10%可分散10只、其中一只翻倍即达标；稳妥型3–5只），**没有个性化配置计算公式**；10%锚是美股统计，A股须另行取数。

## A1 — 应用示例 (Application Example)

### 示例 1: 三型股友分流——同一笔钱的三种命运

- **类型与来源**: 原书策略框架+例题，第九章第四节"思路清晰，无怨无悔"（1.想赌一把的股友／2.想走专业道路的股友／3.想投资股市，但亏不起；3万块翻倍路径为例题演算）。
- **问题/输入**: 三类处境——手里只有3万块想搏翻身的年轻人；有老有小、亏不起的家庭资金；想以炒股为生者。
- **方法论的使用**:
  - 想赌一把的3万块: 铁律是"任何股民做这样赌，请确定赌股的钱是余钱"；按日交易三条注意操作——忘掉基本分析纯用技术图形、看10–30分钟K线（5分钟也成）、亏5%止损赚15%止盈（短线不可照搬"让利润奔跑"）；或什么都不学，彩票式捂一只便宜股碰运气。真赌到3万变300万，就抽250万做年10%的稳妥投资（每年25万，够一家4口）——"穷人闹革命情有可原，富了还闹就是自己添堵"。
  - 亏不起的（股市绝大多数）: 明白自己懂得不多，就不赌大，也不必机械把钱分20份（"那太伤脑筋"）；找3–5只股票按书中买卖原理操作，更大比例的钱交可靠专家；挑管理人只认一条硬标准——一段时间跨度内以低于指数的风险取得超过指数的回报，小心电脑模拟回测出身与炒股竞赛出身者；不想费心就投指数基金（80%的基金管理人拿不出更好业绩）。
  - 走专业道路: 超指数2个百分点已算很成功、凤毛麟角；超指数10%就是"下一个巴菲特"；但"发财的路千万条，炒股发财的路可能是最难的一条！除非您实在迷恋交易，否则千万别尝试"。
- **结论**: 战略定位先行，策略、仓位与回报预期跟着定位走；不同定位之间不可混用预期。
- **结果**: 原书为分流建议框架与例题，未交代具体收益结果。

### 示例 2: 麦道夫的12%——"合理回报"的反向标尺

- **类型与来源**: 原书转述真实事件，第九章第三节"善战者无赫赫之功"。
- **问题/输入**: 麦道夫（纳斯达克前主席）如何赢得大银行、退休金机构、豪门巨富等"行家"的信任。
- **方法论的使用**: 他靠"每年12%、每月1%、年年稳定"的回报赢得信任——因为所有行家都知道，一位有足够知识和经验的投资经理，每年12%的回报"可以在很小的风险之下得到；不容易，但可以做到"。市面上回报比12%更高的基金多的是，但都有起伏、有时亏钱；年年稳定的12%反而最可信。对照锚: 巴菲特1965–2005年年化21.5%已是全球第一。
- **结论**: 年年稳定的12%已是行家级水平——凡承诺"年年翻倍、稳定高息"的方法，在预期管理阶段就应否决。
- **结果**: 麦道夫基金最后规模650亿美元，后被证实为骗局；作者引此例正是说明12%是行家共识的可信回报锚。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 开户前或盘点家庭资产时，问"我该期望股市给我多少回报""每年多少算正常、能不能指望翻倍"；
2. 问"我这种情况该拿多少钱进股市""满仓还是留现金""集中一只还是分散十只"；
3. 在"赌一把翻身／辞职专职炒股／稳妥理财"三条路之间犹豫，要求帮自己定位；
4. 牛市大赚或爆仓大亏之后，问"接下来该继续赌还是收手转稳"；
5. 问"基金/投资管理人怎么挑""指数基金值不值得买"。

### 语言信号 (用户的话里出现这些就应激活)

- "合理回报""年化多少算合理""预期收益""翻倍""财务自由"
- "资产配置""分仓""轻仓""分散""集中一只""指数基金"
- "赌一把""翻身""专职炒股""专业道路""该不该继续"
- "余钱""亏不起""养家钱""有老有小"
- 英文: reasonable return / expected return / asset allocation / diversify or concentrate / index fund

### 与相邻 skill 的区分（初稿，阶段 3 回填定稿）

- 与 `money-management-skill` 的区别: 本卡在**资产战略层**（拿多少钱入市、什么回报预期、分仓轻仓的总原则）；对方在**单笔交易层**（这一注下多大、怎么分批加码、1:3校验）。本卡输出原则，注码计算交给对方。
- 与 `stage-selftest` 的区别: 本卡回答**钱的问题**（资金性质、回报预期、配置）；对方回答**学习阶段的问题**（我在蛮干还是摸索、该练什么）。"股龄<5年"两边都出现，但本卡落点是资金安排，对方落点是训练路径。
- 与 `market-regime-skill` 的区别: 本卡定长期风险定位（总盘子轻还是重）；对方定当下大市方向（可买/观望/离场）——对方的结论是本卡"轻仓到什么程度"的执行输入，不是同一层。

## E — 可执行步骤 (Execution)

**必需输入**: ①资金性质——这笔钱是否余钱、亏光是否影响生活；②家庭责任——有无养家/房贷/学费等刚性支出；③股龄（年）；④回报预期（年化%）。可选: 现有持仓与分散度。①②④缺失时**先询问，不得静默猜值**。

**交付物与完成标准**: 三字段输出，缺一不算完成——①**战略类型**（学习期/赌一把/专业/稳妥之一+判定依据）；②**配置原则**（个股风险怎么分仓+大市风险怎么轻仓+回报预期校准结论）；③**底线**（余钱铁律+对豪赌/杠杆/融资的具体警告）。如实标注: 原书只给参照口径（公共基金单票≤5%即至少20只=充分分散；满足10%可分散10只；稳妥型3–5只），**无个性化配置计算公式**；10%锚为美股统计，A股长期回报需另行取数。

当 skill 被激活后，按以下步骤执行:

1. **资金性质自检**
   - 完成标准: 明确回答"这笔钱亏光了影响生活吗"。
   - 判停条件: 不是余钱而用户仍要高风险操作 → 输出余钱铁律警告并中止分流（"任何股民做这样赌，请确定赌股的钱是余钱"），待用户确认改用余钱或知情坚持后再继续。

2. **股龄与战略分流**
   - 完成标准: 股龄<5年 → 定位学习期（目标=用最小代价了解股市，小注试错，不追求盈利）；股龄≥5年 → 按意愿与处境归入赌一把/专业/稳妥三型之一并给出依据。

3. **回报预期校准**
   - 完成标准: 把用户预期与锚对照（美股指数约10%、60年统计年均近11%、无风险储蓄<1%、麦道夫12%、巴菲特21.5%），并标注"10%为美股口径，A股需另行取数"；预期显著超锚 → 写明对应代价（想翻倍≈只能集中赌一只；想超指数须有跟进升势板块的能力，80%专业管理人做不到）。

4. **两类风险的配置原则**
   - 完成标准: 个股风险 → 分仓（给出两档对照口径并声明不可混用预期: 充分分散档=单票≤5%/至少20只，回报围绕指数；刻意集中档=3–5只按买卖原理操作，博超额也担个股风险）；大市风险 → 轻仓（不满仓、保留现金；1987年黑色星期一道指单日−22.6%，"这一天大约谁都逃不掉"）。两个风险都必须有对应答案。

5. **底线与退出安排**
   - 完成标准: 输出包含——赌赢了怎么办（抽资转稳妥投资）；为什么不做赫赫之功（连续5次100%地赚，一次100%亏就一无所有）；杠杆/融资单票豪赌的案例警告。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问"这一笔该买多少股、怎么分批加码、能不能补仓" → `money-management-skill`（单笔交易层，本卡不算注码）。
- 问"我现在算学股哪个阶段、该怎么练" → `stage-selftest`。
- 问"现在大市能不能买" → `market-regime-skill`；问具体买卖点与止损位 → `critical-point-buy-skill` / `sell-trailing-stop-skill`。
- 需要精确资产配比公式（股债比例、凯利公式等）——原书没有，本卡只给原则与参照口径，不得代作者输出公式。

### 作者在书中警告的失败模式

- 2015年7月中国3万个500万股票户口被消灭——"如果不是试图在股市以高风险赌股，这样的悲剧完全可以避免。在股市，每一分报酬都是以风险做代价得来的"（2016年再版的话）。
- 昌九生化融资爆仓（2013年11月，连续10%跌停七天）: 刘姓投资者自有400多万再融资200多万赌一只股——"没有多年胜利的纪录，怎么敢这样赌？他迟早会倒下，直到他学会敬畏股市"。
- 利物莫以豪赌名扬天下，一生破产三次、死时一无所有——"您可以连续5次100％地赚，只要一次100％亏就一无所有"。
- 作者亲历: 卖空跨式组合期权月赚5%–10%、一年多翻倍有余，三个月后遇大市波动止损出局、利润清零——"充分分散了单个期权的风险，但没法避免大盘的风险"。
- 选管理人陷阱: 电脑模拟回测（统计过去出类拔萃，预测未来通常惨不忍睹）、炒股竞赛出身（通常赌性太强）、基金涨幅远超指数（先问是不是大风险赌出来的、明年亏50%亏得起吗）。

### 作者的盲点 / 时代局限（阶段 0 批判）

- 10%锚为美股统计，作者自认"别的国家可能不一样"、高通胀国家完全不同；A股长期回报须外部取数，不得把10%当A股锚。
- "80%基金跑不赢指数""公共基金单票≤5%"均为美股监管与统计语境，直接套A股公募/私募须谨慎。
- 三型分流靠自我评估，无客观测试；"股龄5年"为经验分界。
- 幸存者偏差: "熬几年可毕业""专职可行"的路径描述来自幸存者样本。
- 对被动投资/指数化浪潮着墨有限（2016年成书）。

### 容易混淆的邻近方法论

- 现代资产配置理论: 作者只借其"充分分散"的结论（第九章明言该理论研究"不同的风险之下如何分配投资"），本书无配比公式——不得把常识性配比（股债平衡等）冒充作者方法。
- 价值投资买入持有: 稳妥型方案仍是"按书中买卖原理操作"（临界点+止损+卖点），不是买了不看。
- "复利"信仰: 复利是战略方向而非保证，前提是"不怎么亏钱"；用复利表倒推"每月赚10%几年财务自由"是对本章的反向误读。
