# 决策规则速查 — 炒股的智慧：在华尔街炒股为生的体验（第四版）

| 能力 | 一句话规则 |
|---|---|
| 股票运动正常性判定 | 四维（走势线/支撑阻力/突破确认/200天线）加量价逐项核对，全过=正常持有安坐，任一破坏=危险信号全部离场、日后可重入 |
| 临界点买点决策 | 买点=公众重新评估股价的临界点，入场触发与止损价同时确定；五类买点+八要点+止损≤20%硬顶，跌回临界点之下即离场 |
| 卖点与移动止损体系 | 运动正常就不卖；卖点由六招触发，移动止损沿浪谷只上移不下移、跌穿当前一级即全部离场——截短亏损，让利润奔跑。 |
| 资金管理与仓位规则 | 胜算>50%才入场；新手本金分6~8份、至少1:3风险报酬比才投一份、分层下注纸面利润才加码、严禁向下摊平——任何时候不输光。 |
| 选股三步过滤 | 选股三步过滤——大市不好什么都不买；选牛劲最足的类别；在牛劲足类别中选龙头老大/特别小弟； 同类候选按"低位爬升>高位跌落、蓄劲期长>短、烫三次不再碰"排序。
 |
| 大市判定清单 | 把指数当一只股票看阶段与正常性，叠加总量背离、六点注意与情绪逆向（全民谈股=顶、大众恐惧=底近）； 大市不好时，别买任何股票——否决级前提。
 |
| 泡沫（疯）识别 | 六特性（可信故事/游资滚雪球/既简单又复杂/已有人赚钱/专家背书/胀得比想象久）核对是否为疯；确认后认清假象、投入其中、公众识破前退出。 |
| 周期四阶段定位 | 把个股长期运动归入蓄劲/爬坡/疲劳/下坡四阶段（均线上呈大弧），按阶段给操作许可；"交易量增加+一举突破阻力线"两条件确认真升势起点。 |
| 心理纪律执行清单 | 交易前内心声音四问＋持有中13条家训与恐惧/贪婪/希望三障碍逐项自检，输出违规项及原书对应纠正规则—— 先查"有没有照规则做"，再谈分析。
 |
| 学股阶段自测与排障 | 按行为症状把学股者定位到蛮干/摸索/体验风险/"久赌必赢"四阶段（约5-6年、不可跳级）， 输出阶段判定＋该阶段训练重点＋典型错误对策。
 |
| 大户操纵痕迹识别 | 钱不撒谎：只认量价痕迹——假跌破支撑放量反弹＝恐慌吸纳（极佳买点）、突破即回落＝假信号、 无消息暴升冲高回落/量增价滞＝派发出货、静默低位放量＝吸筹；操纵只能改短期波动、不能改大势。
 |
| 合理回报与战略定位 | 先按资金性质与股龄分流战略（学习期/赌一把/专业/稳妥），回报预期围绕指数校准（美股约10%锚），用分仓应对个股风险、轻仓应对大市风险，集小胜为大胜靠复利 |
| 250天线简易操作系统 | 只买250日线上方（最好上穿时买）、入场后5%–8%止损、线上坐等、回碰250日线即卖、每笔≤本金10%——四要素齐备的最小系统，牛市抓中间一段，熊市避开 |
| 基本面快速审视 | 大环境八项只作背景；重点核小环境五项（营收势头/盈利/固定资产/同类比较/品牌）+涨三因素（盈利增长——须建立在收入真实增长上、新产品、回购），作技术分析的底层校验，输出红旗项与定性结论 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
