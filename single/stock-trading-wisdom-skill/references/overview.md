## 1. 结构 (Structural)

### 类型
实操手册 + 经验方法论。以"为什么普通股民必然失败"开篇，以"怎样成为能持续盈利的炒手"为主线的个人经验体系；无理论和公式（作者自述），全部论证用心理实验、历史案例、大师引言和作者自身经历支撑。

### 一句话主旨
散户持续亏损的根源是人性而非技术，唯有以"保本（败而不倒）＋小注分仓＋在临界点买卖＋截短亏损让利润奔跑"为纪律、把每次入场的获胜概率从50%提到60–70%，久赌必赢地集小胜为大胜，才可能在股市活下来并最终财务自由。

### 骨架 (主要论点及其关系)

1. **失败的必然性在人性**（第一章）：讨厌风险、发财心急、自以为是、跟风、因循守旧、报复、侥幸七大人性弱点，使一般股民"赚时赚小钱、亏时亏大钱"。
2. **提高胜算的三件知识**（第二章）：基本面（重点看公司小环境与盈利增长/新产品/回购三因素）、技术分析（走势线/支撑阻力线/双肩头肩图/平均线+量价关系）、大市判定；三者共振时胜算最大。
3. **成功要素与资金管理**（第三章）：投机两原理"败而不倒、追求卓越"；保本靠快速止损+别一次下注太多；久赌必赢=胜率>50%+小注；抓住正常运动中的股票安坐不动。
4. **买卖实战=找临界点**（第四章）：买点（升势突破前峰A、突破阻力线、倒头肩破颈线、假跌破支撑线反弹A/B点）、选股三步（大市→牛劲足类别→龙头）、卖点六招（危险信号/保本第一/亏小钱/暴利拿了再说/量增价滞/移动止损A→E）。
5. **纪律清单：华尔街家训13条+大师论**（第五章）：止损/分散风险/别买太多/有疑问离场/忘掉进价/别频繁交易/不摊平/别让利润变亏损/别跟朋友/当机立断/定计划照办/别爱上股票/市场从来不会错。
6. **心理建设从有招到无招**（第六章）：恐惧、贪婪、希望三大障碍的机制与训练方法。
7. **大机会=识别"疯"**（第七章）：南海泡沫/佛罗里达/科威特/中国股疯四案例归纳"疯的六大特性"，参与并在公众识破前退出。
8. **学股四阶段路径**（第八章）：蛮干→摸索→体验风险→久赌必赢；约5–6年。
9. **风险管理收束：善战者无赫赫之功**（第九章，2016新增）：合理回报围绕指数、分仓对个股风险+轻仓对大市风险、复利集小胜为大胜；250天线简易操作系统（再版的话）。

**论点之间的关系**: 层层递进——先破题（人性致败）→ 再给知识基础（分析三件套）→ 立操作框架（要素/资金/买卖点）→ 固化为纪律（家训）与心理（训练）→ 升华到风险与格局（大机会、四阶段、合理回报与复利）。前后多处显式互引（如"请复习第X章第Y节"）。

### 作者要解决的核心问题
"在股市偶尔赚点钱很容易，困难在于怎样不断地从股市赚到钱"——普通人（尤其想以炒股为生者）如何建立一套能重复执行、风险可控、长期为正期望的炒股操作系统。

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 临界点 | 公众对股价重新评估的关键点位（突破阻力线/支撑线、双肩头肩突破点等），在这些点入场获胜概率最高 | 非物理"临界"或技术指标阈值，而是"心理共识翻转点"；买卖技巧全在找临界点 |
| 股票的正常运动 | 正常升势：一浪高过一浪、升时放量回调缩量、回调不破趋势线/支撑/均线；破位即不正常 | 不是"涨得好"，而是"量价形态符合趋势定义"；不正常=危险信号=离场理由 |
| 截短亏损，让利润奔跑 | 一见不对即刻止损缩到最短；有利润则让利润从小跑成大 | 华尔街老话的作者版：对应止损纪律+移动止损+安坐不动 |
| 败而不倒 | 保本第一：本金没了游戏结束；快速止损+别一次下注太多 | 做生意智慧，不只是风控口号，是投机原理第一句 |
| 追求卓越 | 在正确的时候狠狠捞一把（抓大机会、让利润奔跑） | 与"败而不倒"成对，是投机原理第二句 |
| 久赌必赢 | 胜率>50%（经验提到60–70%）+每次只下本金小部分 → 长期必然积累 | 不是鼓励赌，是概率+资金管理的数学结论 |
| 大市 | 股票指数的运行方向（牛市/熊市）；"大市不好时，别买任何股票" | 明确高于个股研判的否决级变量 |
| 牛劲 | 类别股（板块）的上行动能；同形态股票牛劲足者涨幅远大 | 作者自创口语概念，对应板块强度/相对强度 |
| 蓄劲期/爬坡期/疲劳期/下坡期 | 股票周期四阶段，对应经济周期，均线上表现为大弧 | 非教科书阶段论，作者用它替代道氏/波浪的实操替身 |
| 疯（股疯） | 可信故事+游资+简单又复杂+有人赚钱+专家背书+久胀不破 六特性并存的泡沫 | 中性机会词：认清假象，投入其中，公众识破前退出 |
| 摊平（向下摊平） | 亏损时向下加码摊低成本——"破产的捷径"，铁律禁止 | 与教科书"逢低补仓"直接对立（基金定投除外） |
| 套牢/割肉 | 中文特有词：不肯吃小亏的死扛；止损=主动割肉 | 作者以此说明人性讨厌风险 |
| 最小阻力线 | 股票新走势循行的路径，沿此运行阻力最少 | 利物莫概念，作者用于解释趋势的持续性 |
| 好的买入点 | 入场获胜概率最高、且止损位清晰的临界点 | 强调"入场前先定止损"，买点与止损点是同一定义的两半 |

### 核心命题 (用自己的话)

1. 炒股是艺术不是科学：股价从不完全重复，人只能提高概率（>50%），无法消除不确定性。
2. 散户失败的根源是人性七弱点；夏皮诺实验证明人厌恶风险又甘冒大险：赚时赚小钱、亏时亏大钱。
3. 大众买卖的真正原因是价格本身在升/在跌——趋势自我强化，钱不撒谎。
4. 技术分析有效性的根基是人性相近+资金流动的真实性；但指标会"见光死"，只用最简单四图形。
5. 股票运动正常与否可用四维判定（走势线/支撑阻力/突破点确认/均线位置）+量价配合；不正常即离场。
6. 周期四阶段（蓄劲/爬坡/疲劳/下坡）对应经济周期；蓄劲后期爬坡初期放量突破阻力线是真升势起点。
7. 判定大市是前提：用指数当一只股票看它的阶段；顶部见龙头疲软+垃圾股活跃，底部见放量长阳+突破前高。
8. 投机原理=败而不倒+追求卓越；保本两法：快速止损+分层下注。
9. 资金管理是胜率的放大器：新手把本金分6–8份，胜算越大注越大；有疑问的时候离场（胜率回到50%不赌）。
10. 买卖全在临界点：买点永远伴随"跌破X必须走人"的止损点；止损≤20%，越小越好，可定在入场日最低点。
11. 选股三步：先大市，再选牛劲足的类别，最后选该类别龙头/特别小弟；买从低位爬上来的，不买从高处跌下来的（套牢盘=上升阻力）。
12. 卖点六招：危险信号、保本第一（进价上方移动止损）、亏小钱、暴利拿了再说、量增价滞出货、移动止损A→E。
13. 大户操纵必在股价与交易量上露尾巴；假突破、跌穿支撑即刻反弹是经典痕迹。
14. 心理三障碍机制：恐惧使人在底部离场/过早止盈，贪婪使人重注，希望使人拒绝止损；对策是规则前置+重复训练成直觉。
15. 学股四阶段不可跳级，约需5–6年；"业余因大亏破产，专业因小利破产"。
16. 泡沫有六特性可识别；参与大时代级别的大机会是一夜质变的唯一路径，但须在公众识破前退出。
17. 合理回报围绕指数（美股约10%）；分仓对个股风险、轻仓对大市风险；复利+集小胜为大胜才是财务自由正路；善战者无赫赫之功。
18. 250天线简易系统（再版话）：只买250日线上穿品种，5–8%止损，线上坐等，回碰250天线离场，单笔≤本金10%。

### 论证链
人性弱点（心理实验+故事+自述）→ 失败必然 → 需要规则 → 知识三件套把胜算抬过50% → 资金管理保证"亏小赚大"的分布 → 临界点给出具体的买/卖执行点 → 家训把执行固化为纪律 → 心理训练解决"知易行难" → 大机会提供量变到质变的出口 → 四阶段给出学习路径与预期 → 合理回报+复利收束为"善战者无赫赫之功"的价值观。证据类型：①夏皮诺概率实验；②南海泡沫/佛罗里达/科威特/昌九生化等历史案例；③利物莫、巴菲特、索罗斯、巴鲁克、施瓦格引言；④作者亲身亏损与交易记录（如1994-11-02日记、一天亏5万、6年毕业）；⑤简单数学（亏50%需赚100%、分仓组合波动趋近指数、20→27→24→35量价实例）。

## 3. 批判 (Critical) ★

### 作者的时代局限
- 数据与市场环境基于1980–2005美股与1990s初A股：如"70%电脑交易"、庄股操纵生态、佣金结构均已过时；A股现有涨跌停、T+1、两融与量化环境改变了"临界点"的微观结构。
- 汇率、利率对股价的传导描述为教科书式定性，未涉及现代央行沟通与全球流动性框架。
- 250天线操作系统给出具体参数却无回测支撑；对2016年后被动投资/指数化浪潮未及展开。

### 作者的立场盲点
- 幸存者偏差：作者本人与"熬6年可毕业"的路径描述都来自幸存者样本；书中朋友的失败被归因于"选择太多/心不诚"，未考虑结构性随机。
- 中短线动量炒手视角：价值投资仅转述巴菲特一节（且有一处排印讹误"付出不要的价格超出其价值"），对估值、组合再平衡、税务等长线课题着墨极少。
- 所有统计均为个人经验（"我碰到十次有九次赚钱"），无样本量、无基准对照。

### 未被证明的假设
- "人性不变→图形永远有效"：量化交易普及可能削弱经典图形的信号价值（作者自己也承认电脑交易的冲击"答案可不容易做"）。
- 个人能把胜率稳定提到60–70%：仅以自述为证。
- "久赌必赢"隐含每注独立、边际概率不受资金曲线影响：实际有手续费、滑点、税负与连续亏损下的执行变形。
- 假跌破/假突破的识别依赖"大户做盘"叙事，在无庄市场中的适用性存疑。

### 最强反对意见
有效市场与交易成本论：经典技术图形是公开信息，期望超额收益应被成本抹平；行为金融学承认偏差存在，但否认多数人能靠"纪律+6年"克服（作者自己引用的减肥2%成功率恰好支持反方）；其"卖空跨式期权绝招三个月崩盘"的亲身经历，正是高胜率策略尾部风险的活例——低频大额风险没有被"分仓"完全分散。

> **以上批判会直接成为下游 skill 的 Boundary (B) 字段来源**
